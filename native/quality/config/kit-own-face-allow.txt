# the style for a face Glass answers. One line per file: `path | reason`. A reason is required; an entry whose file no
# longer needs it fails K20b. A pane (anything that floats, holds reading content or is a card) is never listed here:
# it asks kitStyledFace, kitSurfaceLook or a liquid face.
