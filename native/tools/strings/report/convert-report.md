## Hand-converted (13 keys, 38 messages)

CMP XML cannot hold these as one resource. Each key has a reviewed recipe in `hand-recipes.tsv`, applied to
every language before conversion, so plural categories, `__eqN` strings, escaping and argument numbering are the
converter's. `HandWords.kt` (generated into `:ui:words`) is the code half:

- **select** → one string `<key>__<branch>` per branch of any language (the text around the select copied in; a
  language without a branch reads its own `other`, as ICU does). `HandWords.<key>(value)` picks the string with a
  `when`; any other value reads `other`. The select argument is no longer a format argument.
- **split-plurals** → `<key>` keeps the sentence with `%N$s` where each plural was, and every plural becomes
  `<plurals name="<key>__<count>">` (+ its `__eqN`). `HandWords.<key>(…)` / `<key>Text(…)` fill the sentence.
  ICU meaning is kept exactly: the sentence never varied with the counts, only the pieces did. A language that
  writes a count as a plain number keeps `%N$d` in its sentence and has no piece.
