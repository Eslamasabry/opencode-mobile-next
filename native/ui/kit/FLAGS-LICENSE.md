# Round flags in the kit

`KitFlagShapes` holds the shapes of eleven flags from the Circle Flags set (https://github.com/HatScripts/circle-flags).

- Licence: MIT, copyright HatScripts. A credit is not required by the licence; this file keeps it anyway.
- Fetched through the agent-glyphs skill (Iconify `circle-flags`), icons us, eg, es, br, fr, it, ru, jp, cn, vn, id.
- The shapes are used as drawing data (SVG path syntax), clipped to the set's own circle; no colour or geometry was changed.
