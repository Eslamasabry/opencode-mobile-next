# OpenCode 2 fixtures (`:protocol:oc2`)

Owner: S1-OC2 (plan 15). These are the Flutter client's OpenCode 2 wire captures, copied byte for byte, so the native
port is held to the same inputs as the Dart client.

| Path | What | From |
|---|---|---|
| `flutter/api2/*` | The 24 api2 fixtures (23 JSON bodies + `events.sse`, a captured prompt round-trip on beta-18600) | `test/fixtures/api2/` |
| `flutter/coverage/oc2_events_samples.json` | 16 event cases, 88 envelopes (every session event family) | `test/fixtures/coverage/` |
| `flutter/coverage/oc2_messages_samples.json` | 21 message cases (every message type, tool and error shape) | `test/fixtures/coverage/` |
| `MANIFEST.sha256` | SHA-256 of every file under `flutter/` (`sha256sum` format) | generated |
| `parity/dart-variants.json` | What the **Dart** parsers decode each fixture to (variant tags and fields) | generated by `tool/dart_variants.dart` |
| `tool/dart_variants.dart` | The generator: runs `lib/api2/models.dart`, `lib/api2/events.dart` and `lib/domain/usage_statistics.dart` | — |

## Checks (in `:protocol:oc2` desktopTest)

- `Oc2FixtureManifestTest`: every file matches its manifest hash, nothing is unlisted, and each copy is identical to
  its Flutter original while `test/fixtures/` still exists.
- `Oc2ParityTest`: every fixture decodes in Kotlin to the same descriptor as `parity/dart-variants.json`
  (the Kotlin side is `ParityDescriber.kt`, a line-for-line twin of the Dart generator).
- `Oc2FixtureDecodeTest`: the fixture assertions of `test/api2_models_test.dart` and `test/api2_events_test.dart`.

## Regenerating

Never edit the copies or the golden by hand.

```bash
# from the repository root
cp test/fixtures/api2/* native/fixtures/oc2/flutter/api2/
cp test/fixtures/coverage/oc2_{events,messages}_samples.json native/fixtures/oc2/flutter/coverage/
(cd native/fixtures/oc2 && find flutter -type f | LC_ALL=C sort | xargs sha256sum > MANIFEST.sha256)
# plain Dart SDK 3.13.7, no Flutter and no pub get: the parsers import only dart:core
native/fixtures/oc2/tool/dart_variants.sh   # DART=/path/to/dart to pick the SDK
```

A new capture (P-N4: OpenCode 2.1.1 / 2.2.5 on the VPS) is added the same way: put it under `flutter/` only if the
Dart client has it too; otherwise add a native-only folder with its own manifest entries and no Dart golden.
