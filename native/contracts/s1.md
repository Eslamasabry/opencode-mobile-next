# Slice 1 contract — interface part (S0-CORE)

Frozen: 2026-11-01 by S0-CORE (branch `native/core-2026-11-01`). Other parts of this file (`XUi`/`XActions`, row
lists, §Deletes) are written by their owners; this part covers only `native/core/{common,model,domain,security,testing}`.

The Kotlin sources are the contract; this page names each frozen surface, where it lives, and the rules a consumer
relies on. A change to anything listed here is a contract change: propose it to the core owner, don't edit core.

Package root: `io.github.eslamasabry.oc.core`.

## §Results — `:core:common` `Outcome.kt`, `Failure.kt`

- `Outcome<T>` = `Ok(value)` | `Failed(failure)`; helpers `map`, `flatMap`, `onOk`, `onFailed`, `getOrNull`,
  `failureOrNull`, `T.ok()`, `Failure.failed()`.
- `attempt(classify) { … }` is the only way to call code that may throw. Cancellation is rethrown.
- `Failure` (closed). App level: `Refused(RefusalReason)`, `Unavailable(FeatureId)`, `StagedRevert`,
  `Folder(FolderProblem)`, `ComputerDidNotAnswer`, `Device`, `Storage(StorageProblem)`, `ProjectGit`, `Termux`,
  `Unexpected`, `Unknown`. Transport: `Failure.Net` = `Offline`, `Unreachable(Why)`, `TrustRefused(Why)`,
  `SignInNeeded(Why)`, `ServerBusy(Kind, WireTag?)`, `NotFound`, `Conflict`, `Rejected(status, tag, WireExtras)`,
  `ServerFailed(status, tag)`, `UnreadableReply`, `DeliveryUnknown`, `StaleRequest`, `NotSupported(FeatureId)`,
  `Incompatible(Kind)` (plan 04 §3.8 table maps every input to exactly one leaf).
- `details: Redacted?` is the only place server prose or exception text may go. Only `Redactor` builds `Redacted`
  (`@RedactorApi` opt-in, error level).
- `Unavailable` = feature absent by capability (never latched); `Net.NotSupported` = the server answered
  404/405/501 for an optional feature (latched per graph, plan 04 §11.5).
- `RefusalReason` and the enums are append-only.

## §Ids — `:core:common` `ids/Ids.kt`

`ProfileId`, `SessionId`, `MessageId`, `PartId`, `RequestId`, `ScheduleId`, `ProjectId`, `WorkspaceId`,
`InboxItemId`, `FormId`, `PtyId` (serializable value classes over `raw: String`), `ConversationRef`.

## §Pace — `:core:common` `pace/`

`Visibility`, `Cadence` (PB-42 enforced in `init`), `TimerSpec`, `Pacer.ticks(spec): Flow<Unit>`,
`DefaultPacer(visibility, random)`, `timerTableProblems(all)`. Tests: `TestPacer` and `assertTimerTable` in
`:core:testing`. First tick one period after collection; immediate tick on return to Foreground; null cadence arms
no timer.

## §Model — `:core:model`

- Profiles: `BackendKind` (serial names `openCode|paseo|codex`), `ServerOrigin` (`toString()` = Dart
  `serverOrigin`), `ProfileTrust`, `ServerProfile` (connection shape — NOT the persisted DTO; S1-DATA owns that),
  `ServerLocation`, `EventLocation`.
- `StreamStatus` (sealed: `Connecting`, `Connected`, `Reconnecting(attempt, nextAttemptAtMs)`,
  `Disconnected(attempt, nextAttemptAtMs)`, `WaitingForNetwork`, `Suspended`, `Stopped(Failure)`),
  `NetworkState(online, transport, metered, defaultNetworkId)`, `NetworkChange`. In `:core:model`, not `:core:net`
  (audit 04 BLOCKER 3).
- Value types ported from `lib/domain/server_gateway/value_types_*.dart` and `models*.dart`: `Sessions.kt`,
  `Requests.kt`, `Prompts.kt`, `Files.kt`, `Catalog.kt`, `Host.kt`.
- `transcript/Transcript.kt`: the plan 09 §2.2 shapes. **Owned by S2-MODEL from here** (behaviour helpers and traps).

## §Gateways — `:core:domain`

- Live: `ServerGateway` = `HealthGateway`, `SessionGateway`, `PromptGateway`, `PermissionGateway`,
  `QuestionGateway`, `FormGateway`, `InboxGateway`, `ProviderGateway`, `FileGateway`, `EventGateway` +
  `capabilities`, `location`, `setLocation`, `awaitActionTransport`, `close`. Forms, inbox and legacy questions are
  inert by default (empty reads, `Unavailable` mutations).
- `PromptGateway.prompt(session, OutgoingPrompt, commandId)` → `PromptAdmission` (`Confirmed` | `Uncertain`, never
  "completed"); a lost response is never resent.
- Optional facets (`Facets.kt`): `SessionRetryGateway`, `CorrelatedPromptGateway`, `MidTurnPromptGateway`,
  `SessionSelectionGateway`, `StagedRevertGateway`, `SessionReadStateGateway`, `McpRemovalGateway`,
  `IntegrationCredentialGateway`, `IntegrationAuthRecoveryGateway`, `IntegrationCommandGateway`, `WebSearchGateway`.
  Engines test with `gateway.facet<F>()`; features gate on capabilities.
- Operations: `ServerOperationsGateway` = `SessionOperations`, `Host`, `Vcs`, `Terminal`, `ManagedShell`, `Catalog`,
  `Mcp`, `Integration`, `Request`. Every method defaults to `unavailable("<capability flag>")`; the name is always a
  real `ServerCapabilities` flag (`FeatureNamesTest`).
- Backends: `GatewayFactory { kind; probe(ProbeTarget): Outcome<ProbeResult>; open(GatewaySpec, ConnectionCoroutineScope): GatewayPair }`.
  `open` does no I/O. Credentials arrive through `CredentialReader` (the net ↔ data seam, audit 03 BLOCKER 3).

## §Events — `:core:domain` `events/GatewayEvent.kt`

`GatewayEvent` (plan 04 §11.2 vocabulary, value-class ids), `GatewayEnvelope`, `RunOutcome`, `InterruptReason`,
`DeltaField`, `NoticeKind`, `RevertKind`, `InboxChange`, `HintKind`, `InstallationKind`, `TerminalChange`, and

## §Capabilities — `:core:domain` `capabilities/`

`ServerCapabilities`: **86** flags (Dart added `claudeAgent` after plan 04 counted 85), names, order and defaults
identical to Dart; `withGenUi`, `withClaudeAgent`, `conversationShellOn`, `flags()`, `flag(name)`, `has(FeatureId)`.
Parity record: `core/domain/src/desktopTest/resources/capabilities/default.json`. `PlatformCapabilities`: the 18
plan 03 flags with `android()` / `desktop()`.

## §Platform services — `:core:domain` `platform/`

`NetworkStatus`, `NetworkGate`, `UnknownNetworkStatus`, `OpenNetworkGate`, `ActivityResults`, `PermissionGate`,

## §Security — `:core:security`

- `Redactor`: `registerSecret` (≥ 6 chars), `forget`, `registerCredentialValues(JsonElement)`, `redact`,
  `containsSecret`, `opaqueTokens`, `diagnostics(text, limit)`, `excerpt(log)`, `details(text)`,
  `details(error, status)`; `RedactingWriter`.
- `AddressRules`: `isLoopback`, `isPrivateNetwork`, `isTailnet`, `classify → HostClass`, `origin(url)`,
  `normalize(input)`, `needsCleartextConsent(origin)`, `normalizePin`, `checkPin`. Refusals are
  `Failure.Refused(InvalidAddress | CredentialsInAddress | PinNeedsHttps)` and never carry the input.
- Links: `ExternalLinkPolicy`, `ApprovedLink`, `LinkDecision`, `ExternalLinkOpener` (unchanged from P1).
