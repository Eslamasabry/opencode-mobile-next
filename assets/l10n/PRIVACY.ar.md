# سياسة الخصوصية

**تاريخ السريان: 7 نوفمبر 2026**

OpenCode لنظام Android تطبيق للاتصال بخوادم OpenCode. لا يوفّر حسابًا أو إعلانات يديرها مطوّر التطبيق. يمكنه إرسال تقارير الأعطال وإحصاءات عن الأجزاء المستخدمة من التطبيق وهل تعمل إلى المطوّر، ولكن فقط إذا فعّلت ذلك (انظر «تقارير الأعطال والاستخدام وصحة التطبيق الاختيارية» أدناه). لا يبيع التطبيق البيانات الشخصية.

## أين تذهب بياناتك

أنت تختار خادم OpenCode الذي يتصل به التطبيق. تُرسل الطلبات وسجل المحادثات والمرفقات المحدّدة وطلبات الطرفية والموافقات على الأدوات وإجراءات مساحة العمل إلى ذلك الخادم عند الحاجة لتنفيذ الإجراء الذي طلبته. وقد يرسل الخادم المحتوى بعد ذلك إلى مزوّد الذكاء الاصطناعي الذي أعدّه مالكه. تتحكم أنت أو الجهات المشغّلة في تلك الخوادم والمزوّدين، وليس هذا التطبيق. تنطبق ممارساتهم المتعلقة بالاحتفاظ بالبيانات والخصوصية على البيانات التي يتلقّونها.

استخدم خادم HTTPS أو نفقًا مشفّرًا. يُقبل HTTP غير المشفّر فقط لعناوين الاسترجاع المحلي التي يستخدمها خادم يعمل على الجهاز نفسه.

## تقارير الأعطال والاستخدام وصحة التطبيق الاختيارية

معطّلة افتراضيًا ولا تعمل إلا بموافقتك. في **الإعدادات > الخصوصية والبيانات** مفتاحان منفصلان، واختيار ثالث يُسأل عنه في كل مرة:

1. **الاستخدام وصحة التطبيق** (`usage`): الأعداد والتوقيتات والنطاقات المذكورة في «الاستخدام وصحة التطبيق» أدناه.
2. **تقارير الأعطال** (`crashes`): بيانات الأعطال المذكورة في «تقارير الأعطال» أدناه.
3. **تقرير مشكلة**: الإعدادات > المساعدة > «إرسال تقرير مشكلة». لا يُرسل شيء حتى تقرأ التقرير كاملًا وتضغط **إرسال**.

في أول تشغيل بعد التثبيت أو التحديث إلى 2.1.5، تسأل النسخة القادرة على الإرسال مرة واحدة: «هل تساعد في تحسين التطبيق؟»، بثلاثة أجوبة: «مشاركة الاثنين» يشغّل `usage` و`crashes`، و«ليس الآن» يبقيهما معطّلين ولا يسأل التطبيق مرة أخرى، و«اختيار» يفتح المفتاحين. ينتقل الجواب الذي أعطيته في نسخة 2.1.5 سابقة: «نعم» على مفتاحها الوحيد يشغّل `usage`، ويشغّل `crashes` أيضًا إلا إذا كنت أوقفت مفتاح «عرض تقارير الأعطال». وفي كل الحالات يمكنك تغيير كل مفتاح متى شئت. الخدمتان تديرهما Google، فتتلقى Google البيانات وفق شروطها: **Google Firebase Crashlytics** لبيانات الأعطال وتقارير المشكلات، و**Google Analytics for Firebase** للأعداد. لا يُجمع أو يُرسل شيء ما دام المفتاح معطّلًا. إيقاف `crashes` يحذف تقارير الأعطال غير المرسلة؛ وإيقاف `usage` يمسح بيانات التحليلات المحفوظة على الهاتف مع معرّف التثبيت العشوائي. لا تتبّع عبر التطبيقات أو المواقع، ولا إعلانات، ولا حساب، ولا شيء يعرّفك باسمك أو بريدك أو رقم هاتفك. لا يحتوي التطبيق على شيفرة إعدادات عن بُعد. كل قيمة تُرسل هي كلمة من قائمة ثابتة أو نطاق ثابت أو رقم أو إصدار بشكل ثابت (ويُسقط التطبيق ما عدا ذلك)، فلا يمكن إرسال نص حر أو رسالة خطأ أو مسار أو رابط أو اسم مضيف أو عنوان أو طلب أو رد أو مفتاح.

### تقارير الأعطال

مع تشغيل `crashes` يرسل التطبيق:

- **الأخطاء القاتلة وغير القاتلة**: نوع الخطأ ومواضع الشيفرة التي وقع فيها دون نص رسالته؛ ولإخفاق عالجه التطبيق اسمًا ثابتًا مع رموز قصيرة (خطوة الإعداد ورمز الخروج واسم حزمة النموذج الصوتي ونوع الرفض). وعطل في شيفرة Android (Java أو Kotlin) يحمل أسماء أصناف الاستثناء ومواضعها فقط.
- **سبب إنهاء Android للتطبيق آخر مرة**: عند البدء التالي، واحدة من crash وcrash_native وanr وlow_memory وexcessive_resource وsignaled وuser_requested وdependency_died وother، باسم `exit_reason`.
- **آخر خطواتك**: آثار بصيغة `area.action` من هذه القائمة الثابتة: `app.start` و`app.foreground` و`app.background`؛ و`nav.open:` ونوع الصفحة (القائمة نفسها في `screen_view`)؛ و`chat.send` و`chat.stop` و`chat.approve` و`chat.deny` و`chat.tool_wait`؛ و`conn.connect` و`conn.drop` و`conn.reconnect`؛ و`linux.step:` وخطوة إعداد، و`linux.fail`؛ و`agent.start:` ووكيل، و`agent.fail`؛ و`update.offer` و`update.install` و`update.fail`؛ و`settings.change:` ومجموعة إعدادات.
- **مفاتيح مخصّصة**: `app_version` (مثل 2.1.5) و`build_kind` (store أو sideload) و`server_kind` (phone أو computer أو none) و`engine_state` (stopped أو starting أو ready أو failing) و`connections` (0 أو 1 أو 2-3 أو 4+) و`oc_server_version` (الرقم الرئيسي والفرعي فقط، مثل 2.0).
- وما تضيفه Crashlytics بنفسها: طراز الهاتف وإصدار Android والذاكرة والمساحة الحرّة وهل الهاتف مفتوح الجذر ومعرّف تثبيت عشوائي والوقت.

### الاستخدام وصحة التطبيق

مع تشغيل `usage` يحصي التطبيق هذه الأحداث فقط، وكل قيمة فيها كلمة من قائمة ثابتة:

- `app_open`: بدء التطبيق (cold) أو عودته من الخلفية (warm).
- `setup_step_reached`: خطوة الإعداد (linux أو essentials أو python أو node أو opencode أو aiteam أو voice أو start أو other).
- `setup_step_failed`: الخطوة؛ ونوع الإخفاق (crash أو timeout أو network أو space أو other)؛ وهل كان وضع التوافق مفعّلًا؛ ووضع Node.js الآمن الذي اعتمده الهاتف إن وُجد (armcap أو threads أو both، أو none_worked إن لم ينجح أي منها، أو other).
- `setup_done`: مدة الإعداد بالدقائق ضمن نطاق.
- `first_reply`: هل الخادم على الهاتف (phone) أم على حاسوب (computer)، ومدة انتظار أول رد بالثواني ضمن نطاق.
- `connect_computer_chosen` و`update_offered` و`update_installed`: بلا أي قيمة.
- `screen_view`: نوع الصفحة من قائمة ثابتة (conversations أو chat أو new_chat أو servers أو this_phone أو setup أو privacy أو appearance أو integrations أو settings أو files أو git أو review أو team أو usage أو agents أو about أو other).
- `feature_used`: الميزة المستخدمة (voice أو camera أو file_attach أو agent_switch أو model_switch أو server_add أو git_action أو review_open).
- `session_length`: الدقائق التي بقي فيها التطبيق في الواجهة قبل انتقاله إلى الخلفية، ضمن نطاق.
- `conn_attempt`: نوع الخادم (phone أو computer)، والنتيجة (ok أو fail)، ونوع الإخفاق (dns أو tls أو auth أو timeout أو refused أو server_5xx أو protocol أو offline أو other)، ومدة المحاولة ضمن نطاق بالميلي ثانية (<500 أو 500-2000 أو 2000-10000 أو >10000).
- `conn_drop`: نوع الخادم؛ والسبب (network_change أو server_closed أو idle_timeout أو background أو other)؛ وهل عاد الاتصال (yes أو no).
- `send_result`: النتيجة (ok أو fail أو queued)؛ ونوع الإخفاق (كما في `conn_attempt` مع rejected أو too_large)؛ ومدة أول رد ضمن نطاق (<2s أو 2-10s أو 10-30s أو >30s أو none).
- `turn_stall`: المرحلة (waiting_tool أو waiting_approval أو streaming أو other)؛ ومدة الانتظار بالدقائق ضمن نطاق (<1 أو 1-5 أو 5-15 أو 15-60 أو >60).
- `queue_flush`: عدد المرسَل وعدد الفاشل، كل منهما ضمن نطاق (0 أو 1 أو 2-5 أو 6-20 أو >20).
- `linux_setup_step`: الخطوة (download أو unpack أو essentials أو node أو opencode أو paseo أو agents أو done)؛ والنتيجة (ok أو fail)؛ والمدة ضمن نطاق بالميلي ثانية (<10000 أو 10000-60000 أو 60000-300000 أو >300000)؛ ونوع الخروج (0 أو 1 أو 126 أو 127 أو signal أو other)؛ والإشارة (SIGILL أو SIGSEGV أو SIGBUS أو SIGKILL أو other أو none)؛ ووضع التوافق (none أو armcap أو threads أو both)؛ والمساحة الحرّة ضمن نطاق (<2 أو 2-8 أو 8-32 أو >32 غيغابايت).
- `agent_start`: الوكيل (claude_code أو codex أو gemini أو antigravity أو opencode أو other)؛ والنتيجة (ok أو fail)؛ ونوع الإخفاق (not_installed أو needs_sign_in أو crashed أو timeout أو other).
- `bg_service_end`: السبب (os_limit أو user_stopped أو idle أو crashed أو other)؛ وهل استثناء البطارية مفعّل (yes أو no).
- `update_result`: النوع (in_app أو patch)؛ والنتيجة (installed أو failed أو declined)؛ ونوع الإخفاق (download أو checksum أو signer أو version أو installer أو other).
- `app_start`: النوع (cold أو warm)؛ والمدة ضمن نطاق بالميلي ثانية (<500 أو 500-1000 أو 1000-2000 أو 2000-5000 أو >5000).
- `jank`: مرة واحدة في الجلسة لكل نوع صفحة: نوع الصفحة (كما في `screen_view`)؛ ونسبة الإطارات البطيئة ضمن نطاق (<1 أو 1-5 أو 5-15 أو >15 بالمئة)؛ ومعدل التحديث (60 أو 90 أو 120 أو other).
- `memory_pressure`: المستوى (moderate أو low أو critical).

ويضبط مرة واحدة هذه الخصائص للجهاز كنطاقات وكلمات: `ram_range` (<3 أو 3-4 أو 4-6 أو 6-8 أو 8-12 أو >12 غيغابايت) و`free_storage_range` (<2 أو 2-8 أو 8-32 أو >32 غيغابايت) و`abi` (arm64 أو arm32 أو x86_64) و`webview_major` (رقم) و`notif_allowed` (yes أو no) و`server_kind` (phone أو computer أو both) و`oc_server_version` (الرقم الرئيسي والفرعي).

تضيف Google Analytics بنفسها معرّفًا عشوائيًا لنسخة التطبيق وطراز الهاتف وإصدار Android وإصدار التطبيق واللغة والوقت وموقعًا تقريبيًا (البلد والمنطقة) تستنتجه من الاتصال دون الاحتفاظ بعنوان IP، وبعض أحداثها الخاصة مثل أول فتح ومدة الجلسة. لا يُجمع المعرّف الإعلاني ولا معرّف Android (SSAID) أبدًا، ولا يملك التطبيق إذن المعرّف الإعلاني، وتُرفض تخصيص الإعلانات وتخزينها، ولا تسجّل Analytics الشاشات من تلقاء نفسها (فقط أنواع الصفحات أعلاه)، ولا تُصدَّر أي بيانات إلى منتجات Google أخرى.

### الأداء

مع تشغيل `usage` يقيس التطبيق أيضًا، عبر خدمة Firebase Performance Monitoring من Google، المدة التي يستغرقها بدء التطبيق والاتصال وأول رد وخطوات الإعداد، ومدى سلاسة الشاشات (الإطارات البطيئة والمتجمّدة). لا يسجّل أبدًا عناوين أو نصوصًا. الجمع متوقف في التطبيق إلى أن تشغّل `usage`، ويتوقف من جديد عند إيقافه. لا تُرسل إلا هذه الآثار الثابتة، لكل منها مدة بالميلي ثانية وسمات كل منها كلمة واحدة من قائمة ثابتة:

- `app_cold_start`: بلا سمات.
- `conn_connect`: نوع الخادم (phone أو computer)، والنتيجة (ok أو fail).
- `send_first_reply`: نوع الخادم (phone أو computer).
- `linux_setup_<step>`: الخطوة (download أو unpack أو essentials أو node أو opencode أو paseo أو agents أو done)، والنتيجة (ok أو fail).
- `agent_start`: الوكيل (claude_code أو codex أو gemini أو antigravity أو opencode أو other)، والنتيجة (ok أو fail).

يسجّل Firebase أيضًا وقت بدء التطبيق ونسبة الإطارات البطيئة والمتجمّدة لكل شاشة من تلقاء نفسه. لا يستخدم التطبيق مراقبة الشبكة في Firebase: لا يُتتبَّع ولا يُرسل أي طلب ويب أو عنوان أو اسم مضيف أو مسار. يُسقط التطبيق كل ما هو خارج القوائم أعلاه قبل أن يُرسل.

### تقرير مشكلة

«الإعدادات > المساعدة > إرسال تقرير مشكلة» يبني تقريرًا واحدًا: آخر 500 سطر من سجل التطبيق القصير الخاص به (الآثار أعلاه والأحداث المرسلة ونوع كل خطأ وما طبعه التطبيق)، والمفاتيح المخصّصة أعلاه، ونهايات عملية التطبيق الأخيرة في Android، وخصائص الجهاز أعلاه. قبل أن تراه يمحو التطبيق المفاتيح والرموز والروابط وأسماء المضيفين والعناوين وعناوين البريد ومسارات الملفات. تقرأ النص كاملًا ثم تختار **إرسال** أو تغلقه؛ والإغلاق لا يرسل شيئًا. لا يتوقف على المفتاحين ويُسأل عنه في كل مرة. يصل التقرير المرسل إلى Crashlytics تقريرًا واحدًا ومعه النص، ويُعرض لك رمز التقرير (أول 8 أحرف من معرّف التثبيت وعدّاد) لتذكره في بلاغ على GitHub؛ ويظهر أيضًا في الإعدادات > حول.

يبقى مفتاح «عرض تقارير الأعطال» المنفصل كما هو: يعرض إعداد تقرير تراجعه وترسله بنفسك عبر GitHub، دون أي طرف ثالث.

## البيانات المخزّنة على جهازك

يخزّن التطبيق بيانات تعريف ملفات الخوادم وتفضيلات الواجهة وحالة الخادم المخزّنة مؤقتًا ونماذج الصوت المنزّلة والمسودات غير المرسلة والصور التي تنتظر الاستعادة والطلبات الموضوعة في قائمة الانتظار أثناء انقطاع الاتصال. تُحفظ بيانات المسودات العادية والصور المعلّقة في ملفات خاصة بالتطبيق، وتُحفظ بياناتها الوصفية في التفضيلات. وتستخدم بيانات مرفقات المحفوظات الجديدة أيضًا مخزن ملفات خاصًا منفصلاً. تُرحَّل بيانات المحفوظات القديمة المضمّنة عند فتح الطلبات المحفوظة؛ وإذا فشل الترحيل، تُحتفظ بالبيانات الأصلية. قد تظل الطلبات في قائمة الانتظار والمحفوظات القديمة التي لم تُرحَّل تتضمن مرفقات مرمّزة داخل التفضيلات. لا تُشفَّر هذه المخازن المحلية بشكل منفصل عن عزل تطبيقات Android. تخضع عناصر قائمة الانتظار لحدود العمر والعدد والحجم الإجمالي. تُحفظ كلمات مرور الخوادم باستخدام التخزين الآمن في Android. النسخ الاحتياطي في Android معطّل لهذا التطبيق.

يكتب إعداد Termux على الجهاز كلمة مرور الخادم في بيئة Termux/Ubuntu الخاصة ليتمكن الخادم المحلي من إعادة التشغيل. احمِ الوصول إلى كلا التطبيقين، وأزل تلك البيئة عندما تتوقف عن استخدامها.

يمكنك إزالة ملف تعريف خادم من التطبيق. ويمكنك مسح كل البيانات المحلية بمسح مساحة تخزين التطبيق أو إلغاء تثبيته. أما البيانات التي يحتفظ بها خادم OpenCode أو مزوّد ذكاء اصطناعي، فيجب حذفها عبر تلك الخدمة.

## جامع الاستخدام المتبقي الاختياري

الاستخدام المتبقي امتداد يُثبَّت بشكل منفصل على الخادم، وليس نقطة اتصال مدمجة في OpenCode. في كل زيارة للشاشة، يطلب التطبيق منك تأكيد أنك ثبّتَّ الجامع أو تثق به قبل طلب مسار Codex الثابت (`/ocmn/quota/v1`) من أصل الخادم المحفوظ نفسه تمامًا، باستخدام بيانات تسجيل الدخول الخاصة بملف ذلك الخادم. لا يُمرّر التطبيق هذه البيانات إلى أصل مختلف ولا يتبع إعادة توجيه.

يجب على المشغّل فرض المصادقة على مسار الوكيل واستبدال بيانات اعتماد العميل برمز قراءة مخصّص للجامع فقط قبل تمرير الطلب إلى الجامع الخاص. إذا أعدّه المشغّل صراحةً، يقرأ الجامع الاختياري ملف اعتماد Codex OAuth واحدًا محدّدًا على الخادم، ويتصل بنقطة الاستخدام الثابتة لدى المزوّد. لا تُرسل رموز المزوّد إلى التطبيق، ولا يجدّدها الجامع، ولا تُكتب في مخزن اعتماد جديد.

يعرض التطبيق فقط فترات الاستخدام الأساسية للحساب بعد توحيد صيغتها، ومعلومات الخطة عند الإبلاغ عنها، وأوقات إعادة الضبط ومدى حداثة البيانات. لا يتلقّى رموز المزوّد أو عنوان بريد إلكتروني مستنتجًا للحساب. جمع بيانات اشتراك Claude غير متاح حتى تتوفر آلية تكامل مدعومة ومسموح بها؛ اختيار Claude لا يرسل أي طلب للحصة. يعيد مسار Claude القديم في الجامع نتيجة «غير مدعوم» دون قراءة بيانات اعتماد Claude أو الاتصال بذلك المزوّد؛ وتُتجاهل إعدادات Claude المتقادمة.

تُحفظ موافقة زيارة شاشة الحصة واللقطات المقاسة في الذاكرة فقط. يمسح تغيير المزوّد اللقطة القديمة ويتطلب موافقة جديدة قبل قراءة مدعومة أخرى من الصفحة. وبشكل منفصل، يمكنك تفعيل المراقبة صراحةً للجامع الموثوق وحساب المزوّد المحدّدين اللذين راجعتهما للتو. تُحفظ موافقة المراقبة وقواعدها لكل ملف تعريف خادم وتستمر بعد إعادة تشغيل التطبيق؛ ولا تُحفظ لقطات الحصة المقاسة. تفحص المراقبة ثلاثة مصادر محفوظة كحد أقصى في كل دورة، كل خمس دقائق في المقدّمة أو كل خمس عشرة دقيقة أثناء نشاط خدمة الخلفية المباشرة الموجودة. تتناوب القوائم الأكبر عبر عدة دورات. لا تبدأ المراقبة تلك الخدمة، وقد يوقفها Android وفق حدوده للعمل في الخلفية.

تتطلب تنبيهات الحصة على الجهاز موافقة منفصلة وقراءة حديثة مبلّغًا عنها تبلغ الحد المحدّد. القراءة عبر Wi-Fi فقط وساعات الهدوء خياران اختياريان. يسجّل التنبيه قراءة سابقة، ولا يضمن الاستخدام المتاح حاليًا. يمكن تعطيل المراقبة من إعداداتها؛ وتزيل إزالة ملف تعريف الخادم قواعد المراقبة المحفوظة الخاصة به. لا تُرفع بيانات الحصة إلى مطوّر هذا المشروع. لا تتحول البيانات غير الصالحة أو المفقودة إلى تقدير للاستخدام المتاح. تنطبق سياسات الخصوصية والوصول الخاصة بالمزوّد، وقد تتغير نقطة الاستخدام الداخلية لديه.

## إعداد مصدر iOS

مشغّل iOS التجريبي مخصّص للتحكم في الخوادم البعيدة فقط. يستخدم مصدره إضافة التخزين الآمن للنظام مع صلاحيات Keychain لكلمات مرور الخوادم، ويصرّح بالوصول إلى الشبكة المحلية للوصول إلى خادم تختاره. لا يفعّل إعداد Termux أو خدمة الخلفية أو الإشعارات أو الكاميرا أو الإملاء المحلي أو جسور استقبال المشاركات الخاصة بـ Android. يظل التحقق الأصلي من Keychain والإضافات وبيان الخصوصية متطلبًا قبل توزيع iOS؛ فالبنية الأولية للمصدر أو ناتج المحاكي ليس تطبيق iPhone منشورًا.

## استعادة تسجيل الدخول المعلّق لدى المزوّد

للخوادم المدعومة، يحتفظ التطبيق ببيانات وصفية محدودة لاستعادة تسجيل الدخول لكل ملف تعريف خادم: معرّفات المحاولة والتكامل، ونوع الطريقة والوضع، والأصل الأصلي وموقع المشروع أو مساحة العمل، ووقت انتهاء صلاحية الاستعادة. لا يحفظ عنوان تفويض المتصفح أو الرمز أحادي الاستخدام أو الإجابات المرسلة أو رموز المزوّد. الاستئناف والفحص والإلغاء والنسيان المحلي إجراءات صريحة. نسيان سجل محلي أو حذف ملف تعريف لا يلغي تسجيل دخول بعيدًا ولا يسحب بيانات اعتماده. يُفصح عن فشل عمليات الحفظ لأنه لا يمكن معها ضمان الاستعادة بعد إعادة تشغيل التطبيق.

## تشخيص التطبيق

تُحفظ أخطاء التطبيق وبدء التشغيل التي تمت معالجتها في ذاكرة العملية فقط، بحد أقصى 20 إدخالاً، وتختفي عند انتهاء عملية التطبيق. يحجب التطبيق رؤوس التفويض والقيم التي تشبه بيانات الاعتماد وبيانات الاعتماد والاستعلامات في عناوين URL والسلاسل الطويلة التي تشبه الرموز. لا يضيف رسائل المحادثات أو محتويات الملفات إلى هذه التقارير.

لا يُرسل التشخيص تلقائيًا أبدًا. إذا ضغطت صراحةً على **إرسال** في تشخيص التطبيق، تُرسل الإدخالات المحجوبة المعروضة حاليًا على تلك الشاشة إلى خادم OpenCode المحدّد مع سياق الدليل ومساحة العمل النشطين. يظل النسخ والحذف إجراءين محليين.

## الميكروفون والإدخال الصوتي المحلي

يُطلب الوصول إلى الميكروفون فقط عندما تبدأ الإدخال الصوتي. يُحوَّل الصوت المسجّل إلى نص محليًا على الجهاز باستخدام نموذج كلام منزّل. لا يرفع التطبيق التسجيل، ولا يرسل الإدخال الصوتي طلبًا تلقائيًا أبدًا. يُرسل النص الناتج فقط إذا اخترت إرساله ضمن طلب.

## القراءة بصوت عالٍ الاختيارية

على Android، تتطلب قراءة نص الرد تأكيدًا قبل الوصول إلى محرّك الكلام في النظام. يُرسل نص المساعد المحمّل إلى ذلك المحرّك المثبّت بشكل منفصل؛ وتُستبعد كتل الشيفرة وتفاصيل الأدوات. لا تُعرض إلا الأصوات المعلّمة بأنها تعمل دون اتصال، لكن هذه البيانات الوصفية لا تضمن العزل عن الشبكة؛ فممارسات الخصوصية الخاصة بالمحرّك هي التي تنطبق. لا يحفظ التطبيق مدخلات الكلام ولا ينزّل الأصوات تلقائيًا. يعمل التشغيل في المقدّمة فقط، ويمكن إيقافه صراحةً، ويتوقف عند الانتقال إلى الخلفية أو تغطية المحادثة أو تغيّر النطاق أو فقدان التركيز الصوتي. قد يسمع الأشخاص القريبون الصوت.

## الملفات والوصول إلى الطرفية وTermux

يقرأ التطبيق ملفًا محليًا بعد أن تختاره من منتقي ملفات أو صور أو تلصقه أو تلتقط صورة صراحةً. يُستخدم إذن الكاميرا أيضًا للاقتران عبر رمز QR. تُحفظ الصور المختارة محليًا مع محادثتها الأصلية حتى تُضاف إلى مسودة أو تُحذف، بما في ذلك الاستعادة بعد انقطاع منتقي Android. لا يطلب التطبيق الوصول إلى مكتبة صورك بالكامل. يُرسل المرفق إلى خادم OpenCode المحدّد فقط عندما ترسل الطلب. تُحمَّل الملفات المفتوحة من مساحة العمل من ذلك الخادم.

إذا فعّلت الإعداد على الجهاز، يستخدم التطبيق إذن Termux الصريح `RUN_COMMAND` لتثبيت خادم OpenCode على جهازك وتشغيله وتحديثه والتفاعل معه. يستطيع OpenCode قراءة الملفات وتشغيل الأوامر التي تسمح بها بيئته المضيفة. تعامل مع الوصول إلى خادم OpenCode كما تتعامل مع الوصول إلى طرفية ذلك الجهاز.

## وضع الخلفية والتحديثات

يحافظ وضع الخلفية الاختياري على اتصال أحداث الخادم والطرفيات باستخدام خدمة مقدّمة في Android مع إشعار دائم. وقد يستهلك طاقة إضافية. لا يُطلب الإعفاء الاختياري من تحسين البطارية إلا بعد أن تختاره من الإعدادات.

أثناء تفعيل هذا الوضع ووجود التطبيق في الخلفية، يمكن لـ OpenCode أيضًا عرض إشعارات عامة عندما تحتاج جلسة برمجة إلى إذن أو إجابة، أو عند اكتمالها أو فشلها. تتعمّد هذه الإشعارات إخفاء نص الطلب ومدخلات الأدوات وأسماء الملفات وعناوين الجلسات وتفاصيل أخطاء الخادم عن شاشة القفل.

يستخدم التطبيق Shorebird للتحقق من تحديثات الشيفرة المتوافقة وتنزيلها. تكشف طلبات التحديث بالضرورة معلومات الشبكة، مثل عنوان IP ومعرّفات التطبيق والتحديث، إلى Shorebird. تحكم شروط الخصوصية الخاصة بـ Shorebird هذه المعالجة.

## شعارات المزوّدين

تعرض شاشات المزوّدين وكتالوج النماذج ومنتقي النماذج شعارًا بجانب كل مزوّد ذكاء اصطناعي، وتعرض شاشات الوكلاء شعارًا بجانب كل وكيل برمجة. شعارات الوكلاء والمزوّدين الشائعين رموز أحادية اللون مضمّنة داخل التطبيق، فلا يُرسَل أي طلب عبر الشبكة لعرضها. أما المزوّد الذي لا يملك شعارًا مضمّنًا فيُنزّل التطبيق شعاره من models.dev (`models.dev/logos`) باسم المزوّد، مثل `/logos/example-ai.svg`. لا يُرسَل شيء عنك أو عن خادمك أو جلساتك؛ يحمل الطلب الاسم وعنوان IP فقط، كما يحدث عند تحميل أي موقع. تُخزَّن الشعارات المنزَّلة على الهاتف وتُحدَّث مرة في الأسبوع على الأكثر، وتُحذف مع بيانات التطبيق. إذا فشل التنزيل أو كنت دون اتصال، يعرض التطبيق رمزًا من حرفين بدلًا منها.

## الأذونات

- **الإنترنت:** الاتصال بخادمك وتنزيل نماذج الصوت المحلية وفتح الروابط والتحقق من تحديثات التطبيق.
- **الميكروفون:** التقاط الصوت فقط أثناء استخدام الإدخال الصوتي المحلي.
- **الإشعارات وخدمة المقدّمة:** عرض الحالة الدائمة وتنبيهات البرمجة التي تحافظ على الخصوصية ويستخدمها وضع الخلفية الاختياري.
- **الإعفاء من تحسين البطارية:** طلب اختياري لجلسات البرمجة الطويلة.
- **إذن أوامر Termux:** التحكم الاختياري في خادم OpenCode على الجهاز.
