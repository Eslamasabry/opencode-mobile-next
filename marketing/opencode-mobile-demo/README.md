# OpenCode mobile outreach demo

`opencode-mobile-outreach.mp4` is a short, caption-led vertical demo for sharing
with the OpenCode maintainers and community.

The footage was recorded from the Android release build against a real OpenCode
server running in Termux. It shows:

- reconnecting to server-backed sessions;
- OpenCode-supplied models, modes, agents, context sizes, and capabilities;
- rendering a tool-produced image as an interactive artifact;
- opening that artifact and attaching it back to the prompt; and
- running `opencode --version` in the integrated terminal.

The cut intentionally excludes server credentials, configuration screens,
private logs, and notification content. It uses no copyrighted music and remains
understandable when autoplayed without sound.
