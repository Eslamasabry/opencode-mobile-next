# Outreach copy

## Primary post

I've been exploring what a mobile companion for OpenCode could feel like—not a
replacement for the terminal, but a way to continue real coding sessions away
from the desk.

It connects directly to OpenCode, discovers its models and modes, survives
Android background and wake cycles, renders generated artifacts, supports
open/download/attach-back workflows, formats Markdown/code/JSON, and provides
mobile diff review.

I'd love feedback from the OpenCode maintainers on the API boundaries and
artifact contract—and whether this direction could be useful to the wider
community.

Demo + source: https://github.com/Eslamasabry/opencode-mobile-next
