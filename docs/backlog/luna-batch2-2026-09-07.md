## Coordination

only its fence. Workers share the checkout and preserve other edits. Root owns
`connection.dart`, `profiles.dart`, `main.dart`, all chat parts, shared gateway
contracts, localization and generated output; cross-fence edits require lead
integration. Workers supply new copy as temporary JSON fragments and never edit
ARB. The native share worker exclusively owns `MainActivity.kt` for this batch.

allowed with the pinned 3.47.2 Dart. Focused regressions precede the frozen full
recursive serial suite, SDK checks, debug build and ADB checks. Root audits
source and actual behavior; documentation or extra tests alone do not count as
one of the 20 implemented items. Logical commits land directly on `dev`, all
with `[skip ci]`, followed by a verified push. Existing unrelated artifacts
remain untouched. Private handover files remain outside this repository.
