Codex on Android

OpenCode Mobile is an unofficial Android app that runs Codex alongside nine other coding agents. Run it on the phone in the app's own Linux, or connect to Codex on your computer.

Download for Android See the whole app

What it does

Pick Codex for a conversation and ask for a change. The app shows what it is doing, asks before it runs a command, and shows the result as a diff you can review line by line. Each conversation keeps its own agent, model and history, so you can use Codex for one task and another agent for the next.

How setup works

  1. Install the APK from GitHub Releases.
  2. Choose On this phone for the guided setup of Ubuntu, Git and Node (about 210 MB, use Wi-Fi), or On my computer to connect to Codex running there.
  3. Sign in with your OpenAI account or key for Codex. The app does not include a model subscription.

Limits to know

  • Android 8 or newer; on-phone agents need a 64-bit phone.
  • Installed from an APK, not the Play Store.
  • Claude Code and OpenCode are the best proven agents on phones; Codex and the others are newer and less tested on real devices.
  • Models run at OpenAI, not on your phone.
