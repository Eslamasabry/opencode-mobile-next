# Native UI rebuild: batches and orders (2026-11-05)

Every order the swarm runs, in dependency order. Binding rules: [GOLDEN-STANDARD.md](GOLDEN-STANDARD.md). Machine-readable: [orders/INDEX.tsv](orders/INDEX.tsv) (one row per order) and [tracker.json](tracker.json) (one item per part, school and screen).

## How this list was made

- **Orders 01-34 are the port plan's batches 1-34, same numbers, same parts** (`docs/design/native-looks-2026-11-04/port-plan.md`, generated by `native/tool/design/port_plan.py`, commit da9ab7802). What this list adds to each batch: a disjoint native write set (each native file has exactly one owning order), the scene-named galleries the plan left unassigned (333 goldens: `kit_action_*`, `kit_confirm_*`, `kit_step_light_*` and the other `kit_*` galleries go to the order of their part; `kit_scenes_*` to 29-30; `kit_surfaces_*`, `kit_controls_*`, `kit_fields_*` to the school galleries 36-37), the live-look goldens in `test/goldens/live_styles/`, the capacity classes of `test/kit/kit_capacity.json`, engines, dependencies and the gate.
- **Batch 34 is unparked.** The plan parked `glass/kit_glass.dart` under the 2026-10-26 rule; the owner now wants Glass as a user-selectable school (2026-11-05). Order 34 ports `kit_glass.dart` plus the Glass painting and words plate from GLASS_REF `1bbdc3f9c`; order 03 ports the Glass spec beside the other five; order 35 brings back the painted aurora (`auroraImage`) and the vivid wash.
- **Orders 36-37** verify the schools on the Flutter school galleries. **Orders 40-53** rebuild the screens, one order per group of native feature modules, every row of the screen inventory (`docs/design/native-rewrite-2026-11-01/plan/07-screens-navigation.md` §5) routed to one of them.
- **Folded parts.** Where the plan names a Dart file whose native code lives in a file another order owns (for example `kit_surface_look.dart` → `Surface.kt`, owned by 03; `kit_sheet_frame.dart` → `KitSheet.kt`, owned by 11), the Dart file stays in its batch for verification and the owner ports it.

Totals: **52 orders** (00 done by the lead, 51 for the swarm), **282 parts** (278 Flutter kit files at FLUTTER_REF + 4 Glass files at GLASS_REF), **6 schools** × light/dark, **166 screens** (164 inventory rows + the deferred AI Team and FactsBook families), 4527 goldens in the gate manifests.
