What `TeamParts.kt` holds:

- `KitTeamRules`: `teamTone` (`:9-13`), `teamIcon` (`:15-24`), the progress rule (`:83-87`, value `completed / total`),
  the row end (`:100`), the stale/loading no-actions rule (`:144-145`, `:196-197`), the card head (`:153-179`) and the
  attention alphas `.30` edge (`:217`) and `.09` fill over `surface1` (`:227`).
- `KitTeamGlyphs`: the nine Material glyphs Flutter draws (`Icons.inbox_outlined`, `hourglass_empty`,
  `pending_outlined`, `notifications_none`, `pause_circle_outline`, `error_outline`, `check_circle_outline`, `history`,
  `chevron_right`) as 24-grid vectors (Material Icons artwork, Apache-2.0). The kit's `KitIcons` is the Phosphor set and
  has none of them, and the order may not edit `KitIcons.kt`, so they live with the part. `chevron_right` mirrors in RTL
  as Flutter's `matchTextDirection` glyph does.
- `KitTeamRow` (Dart `teamRow`) and `KitTeamCard` (Dart `teamCard`), built only from kit parts (`KitText`, `KitIcon`,
  `KitTappable` with Flutter's default square shape, `kitSurfaceLook` for the card face, `KitActionBlock`). The progress
  bar is Flutter's determinate `LinearProgressIndicator` as `teamRow` sets it (`space1` high, `text2` on `surface3`,
  filling from the start edge, with progress semantics).
- Attention card: Solid gets the amber-tinted fill; every style gets the `.30` amber hairline edge (Solid through the
  shape's side, the other styles as a foreground edge, `:215-255`); one `border` over the card outline draws both.

Motion: Flutter's team parts have no animation of their own; the card face follows the kit's 200 ms style fade
(`KitSurface`, reduced motion snaps). No motion was added, per standard §1 (no improvements over Flutter).

Words: none. Every string the parts draw is supplied by the caller (as in Flutter), so no `strings_rb28.xml` files
were created.
