## Folded gaps (part-kit_page_route → order 03 `part-kit_page_transitions`)

Native page transitions do not live in order 03's files (`KitGrow.kt`, `KitModalMotion.kt`, `KitPredictiveBack.kt`) but
in `ui/shell/.../nav/ShellMotion.kt` (no order). Compared with kit_page_route.dart:

- Android: fade-forwards 450 ms, quarter-width travel, fade in over 75 %, out over 25 % — ported (ShellMotion).
- Non-Android (the `kit_page_route_mid_forward/_mid_reverse` goldens, `KitPageTransitionsBuilder`, `KitMotion.standard`):
  no native equivalent; desktop uses the same fade-forwards.
- `reverseTransitionDuration` capped at `KitMotion.rowReturn` when the page grew from a row (`KitPageOrigin.grewFromRow`):
  covered by `KitGrow` (order 03); not re-verified here.
- Reduced motion: `transitionDuration` zero and `popGestureEnabled` false — ShellMotion's Off level is instant; the
  pop-gesture rule was not checked.
- No native gate case can render a mid-transition page route through the kit, so the six goldens have no gate row.
