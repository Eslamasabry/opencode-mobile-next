## M01 Style

Both the WidgetPanel.Style route and Android's currently used widgetactions adapter use the kit form: preview,
Small/Medium/Wide segments, Background segments, six accent swatches and the selected name, then Save style. Choices
hold during saving. The older adapter's preview size is local presentation state, like Flutter's nonpersisted preview.
Failed saves show neutral copy and retain choices. Existing scoped save callbacks and host close behavior are preserved.

## M02 Project

Both adapters show All projects then each complete project value in a radio list. Empty project ids do not duplicate
All projects. One selection calls the existing scoped save and closes through the existing successful-save host path;
the older adapter now calls project(value) then save() on the same tap. Saving holds choices and dismissal; failure
keeps the selected value and explanation. No navigation or profile target is reconstructed by the screen.

## M03 Steer/Voice

The new route and current Android adapter use KitSteerBox: title/Close, two-to-five-line field, microphone and Send in
one row, neutral outcome copy and an accepted check. Empty/blocked/sending states hold Send, draft survives failure,
and sends use trimmed text. Voice uses existing automatic dictation startup; the UI consumes dictated additions once.
The old adapter retains its visible Finish recording action because its voice contract uses in-app capture instead
of the Flutter speech window. Accepted messages close after Flutter's 700ms through the existing close action.
Rejected/uncertain acknowledgements keep the draft and offer the existing Open conversation path; they never resend.

## State limits

Android currently calls feature/widgetactions; its WidgetActionUi has no steerMode or typed rejection reason. It cannot
safely distinguish Add to this turn from Send after this reply, or return a rejected request to an editable/retryable
state. Its existing generic Message this conversation title and conservative acknowledgement guard remain. The newer
WidgetPanelUi has steerMode and renders the exact two titles. These differences are blocked on presentation, not hidden.
