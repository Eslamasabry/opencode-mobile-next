notifications and server counts), with the kit moving values below the title when text needs room. Conversation

## Privacy and local data

one combined Storage used summary; Clear queued prompts and Clear drafts with their counted explanations and

`LocalDataUi.result` lacks the deleted kind, so its existing safe generic result notice remains.
