## What is on the branch

- **Browser capabilities** (`lib/platform/platform_capabilities.dart`):
  `secureContext` (read from the browser's own `isSecureContext`),
  `usesDesktopInteractions`, `supportsClipboardRead`,
  `supportsSecureCredentialStorage`, `supportsAgentSocketConnections` (false in
  a browser; `supportsCodexConnections` is the same answer),
  `PlatformCapabilities.browser()` for tests.
- **Navigation and input**: desktop shortcuts, right-click menus, scrollbars,
  selection and file drop on a desktop browser; Alt+N / Alt+W in place of the
  browser-reserved Ctrl+N / Ctrl+W (18 bindings in a browser, 20 on a native
  desktop); the browser menu is held off only while the pointer is over a
  `KitContextRegion`, so a text field keeps its Paste.
- **Servers**: Codex and Paseo are disabled with the reason on Add server, say
  why on a saved row and on Connect, and are never auto-connected at the app
  root; `connect()` refuses them before building a transport. The Paste buttons
  (pairing, secret fields) are not built where the clipboard cannot be read, and
  a sentence points at keyboard paste into the address field, which already
  recognises a pairing payload. On a plain-http network origin the form says,
  before a password is typed, that the browser will not keep it.
- **Help > Browser mode** (web only; `settings-browser-mode`): what works, what
  needs the phone app, and the facts of this page (secure origin, mixed
  content, CORS). About, the guide's security note and bug reports describe the
  browser build.
- **Transports** (`lib/network/`): stream requests (the OpenCode 2 event stream,
  the session log, Gas City) go through `fetch()` + `AbortController` so frames
  arrive as sent; the OpenCode 2 terminal opens its single-use ticket URL
  through the browser WebSocket; a failure with no HTTP answer is one honest
  sentence ("the browser cannot tell a stopped server from an address it
  blocks") instead of "refused" or "host not found". A2A uses `fetch` with the
  same bounds.
- **Storage**: profile metadata and preferences in site storage; secrets
  through the secure-storage web plugin (WebCrypto, secure context only, no
  plaintext fallback); draft, photo and stash attachment bytes in IndexedDB
  (one database per vault root); a secret that no longer decrypts asks again;
  profile deletion removes the payloads. `PRIVACY.md` says what the browser
  keeps and what it does not protect against.
- **Fixes the port found**: `isPrivateNetworkHost` used `dart:io`'s
  `InternetAddress.tryParse`, which throws on the web (every plain-http server
  address passes through it; it now uses `Uri.parseIPv4Address` /
  `parseIPv6Address` with the same verdicts); `AndroidByoHostSigner.supported`
  read `Platform.isAndroid` at `ProfileStore` construction, which throws on the
  web; the on-disk problem report is skipped in a browser instead of logging
  "unavailable" on every load. The terminal's Paste item is not offered where
  the clipboard cannot be read (keyboard paste into the terminal still works).
- **Copy**: 24 keys in `app_en.arb` and `app_ar.arb` (`browserMode*`,
  `browserEditor*`, `browserPairing*`, `browserAgentSocket*`,
  `browserTransportFailure`, `browserProbeTimeout`, `aboutBrowserSummary`).
  The browser failure sentence no longer appends the browser's raw error text.

## Not verified, and the traps to look for first

- **Nothing here has booted in a browser.** `dart:io` is importable on the web
  but throws when used (`Platform.*`, `InternetAddress.*`, `File`, `Process`,
  `HttpClient`). The startup path and the connect path were read for those and
  the two that threw were fixed, but the int tree grew by thousands of commits
  since the web slice last booted; the first `flutter build web` and a page
  load are the real test. Grep first for `Platform.` and `InternetAddress` in
  any new failure.
- Codex and Paseo stay unavailable by design; Paseo's bearer subprotocol would
  allow a browser socket, but its client opens a detached `dart:io` upgrade and
  would need its own platform split.
- Shift+F10 / Menu key inside a hovered region opens the app menu, and the
  browser may also open its own; a page-wide disable would cost the browser
  Paste in text fields on non-secure origins. macOS Option+N / Option+W may
  compose a dead key on some layouts. ChromeOS reserves more accelerators.
- Voice, read-aloud, camera QR pairing, background monitoring, notifications,
  the home-screen widget, launcher shortcuts and servers on the device are
  absent by design; the Browser mode page names them.

## Owner decision

Whether to ship a web target at all, and from where. A password can only be
kept on an HTTPS origin or on `localhost`; the Tailscale preview at
`http://100.126.15.6:8789` is not secure, so it works for servers without a
password only. Shipping needs a hostname and certificate (or a reverse proxy),
the server's CORS allow-list for that origin, and a place to host the build
(`flutter build web --no-web-resources-cdn`; the CDN does not serve the
Shorebird engine revision). Nothing on this branch publishes or hosts.
