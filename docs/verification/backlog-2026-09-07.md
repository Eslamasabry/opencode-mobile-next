## Scope, privacy, accessibility and persistence

Plugin inventory retains only bounded IDs, validated package names, source
kinds, status and the declared terminal UI flag. Raw loader errors, source
paths/URLs and options are excluded. Rows are flat, status has text plus icons,
and enlarged-text behavior has focused coverage.

MiniMax uses the provider-documented Subscription Key endpoint, pinned official
CLI field semantics, explicit file configuration, fixed vendor host and
source-bound identity. Only reported general-pool percentages are shown.
Required timestamp drift is invalid, unlimited/boosted/absent measurements are
not fabricated, and PAYG keys do not become subscription quota. The phone sees
no provider key. [Collector sources and deployment requirements](../../tool/quota/README.md).

Health checks call the existing status command only. That command can reconcile
stale manager bookkeeping, but never starts or restarts a server. The view
labels its observation time and does not equate a live process with verified
authenticated server health or guaranteed overnight lifetime.

Handoff syntax was inspected from the installed CLI with `opencode attach
--help` (no server launched). The command is POSIX-shell quoted, excludes the
password, and requires a reachable HTTPS server. Clipboard confirmation binds
the reviewed session, project, directory, workspace and rebuilt command.

The demo owns its gateway, event channel, controller, preferences, profile
identity and handoff store. Isolation suppresses network transport construction,
native background handler registration, widget publication and routes/actions
that could escape the simulation. It does not replace global preference or
platform singletons. No persistent format migration is introduced by these
new slices.
