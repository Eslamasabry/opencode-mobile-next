## What it is

A turn's work is one quiet line (glyph, plain words, chevron; the working mark in the glyph's place while it runs; no pill). Opening it shows a timeline **in place** under the line, no sheet:

- a thin rail down the start edge (the right under Arabic), joined to the line's glyph;
- a small grey **dot** for a sentence (a thought, prose the agent said between steps);
- a small **tile** with the step's glyph for a tool call, with the step's words in bold and the file or detail muted under it;
- the step's state in the node's place (the live mark for the step in progress, the failed, waiting and stopped marks);
- a **preview card** under a finished file write or edit: at most 6 lines with `+1`, `+2` numbers in mono, fading when more follow; a tap opens the existing full view (the step's body);
- the running step last, carrying the one live mark.

Same data as before (`KitToolRow`, `KitMessage.thought`, the host's `ToolCard`), so OpenCode 1, OpenCode 2 and Claude Code turns all get it.
