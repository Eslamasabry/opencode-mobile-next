# One label for every tool name — 2026-10-08

Branch `fe/timeline-tool-names` from `feat/genui-fe` (`c46ed35f`). Follows `fe/chat-turn-fixes`: that branch worded tool ids in the transcript, but the timeline sheet and other surfaces still showed raw ids.

## One label function

- `lib/domain/tool_label.dart` holds the facts about tool ids:
  - which ids are the agent card tool (`isAgentCardTool`);
  - which id is Claude Code's background-task notice (`isBackgroundTaskNotice`, `backgroundTaskEnd`);
  - how any other id becomes words (`toolIdWords`: "render_mermaid_diagram" → "render mermaid diagram", "mcp__github__create_issue" → "create issue").
- `toolLabel(rawName, {state, l10n})` in `lib/ui/widgets/tool_card_contract.dart` returns the name a step row shows (`_ToolContract.title`). Every UI surface that names a tool now calls it.

| Surface | Before | Now |
|---|---|---|
| Transcript step rows, running work line | worded since fe/chat-turn-fixes | same contract |
| Timeline sheet row, "Tools: …" | raw ids | `toolLabel`, each name once |
| Timeline search hit / Find in conversation excerpt | `oc-ui_show oc-ui_show {…}` | `TranscriptSearchIndex(toolLabel: …)`: the label instead of the id; a server title that repeats the id is dropped |
| Copy / export transcript | `### Tool: oc-ui_show` | `transcriptToolHeading` → `### Tool: Show card` |
| Permission request title, "always allow" target | `Use mcp__oc-ui__show` | `Use Show card`; the raw id stays under the request's Details |
| Live notification (`ConnectionController.toolSentence`) | `Running oc-ui_show…` | "Showing a card…", "Checking a background task…", otherwise `Running <words>…` |
| Team agent "Last step" | `Used task_notification` | `agentStepWords` → `Used Background task finished` |
| Conversation list previews | text parts only (session tail cache) | none of these reach it |

## Guard
