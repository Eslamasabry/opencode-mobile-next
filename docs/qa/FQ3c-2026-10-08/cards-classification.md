## Finding

**Confirmed harness false-negative predicate; archived runtime cause remains unproven.** The probe requires raw `executed:true`, but stable OC2 publishes `executed` as provider-execution provenance: a successfully completed local MCP call can have `executed:false`. The app already normalizes completed local calls correctly. The sanitized [2196 phase](../FQ3b-2026-10-08/fq3-20261008b-cert-opencode2-cards.json) records an app-managed OC2 2.0.10 server, explicit `opencode/big-pickle`, and `cards_tool_call_missing`. It records no tool inventory, real card call input/output or answer receipt. That code therefore does not prove an absent real call, a server limitation, an app mapper defect, or a tagged-answer defect.

OC2 cards remain deliberately unqualified in `lib/domain/agent_tools/agent_tool_adapter.dart:175`. `BuiltinGenUiSetupVerifier` rejects unqualified adapters, and its generated verification script accepts only Claude/OC1 (`lib/builtin/agents/gen_ui_install.dart:43`; `gen_ui_install_scripts.dart:364`). Source and fake-wire coverage must not promote this gate.

## Pinned server evidence

The archived tree SHA is `b8cedc1a7a5e2916bbb65dc1d4b620729c261638`; both its [core package](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/core/package.json) and the [v2.0.10 package](https://raw.githubusercontent.com/anomalyco/opencode/v2.0.10/packages/core/package.json) declare 2.0.10.

The stable [MCP config plugin](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/core/src/config/plugin/mcp.ts) consumes `mcp.servers` and reloads on config updates. The [MCP tool adapter](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/core/src/tool/mcp.ts) registers tools under the server namespace, carries `codemode:false` through to direct registration, and asserts permission action `oc-ui_show`. The [tool runtime](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/core/src/tool/runtime.ts) produces effective namespace-prefixed names. Thus this app-owned server/tool pair is correctly named `oc-ui_show`; stable 2.0.10 supports this route. Plugin/custom-tool support is also described by the pinned [tools contract](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/specs/v2/tools.md). None of this proves the specific running location had the tool connected.

The pinned [session publisher](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/core/src/session/runner/publish-llm-event.ts), lines 430–436, stamps tool calls with `tool.providerExecuted`. Its local `toolExecution` path, lines 535–552, publishes terminal success with content and that same flag, without changing it to true. A local success is therefore a concrete counterexample to the probe's raw-true requirement. This is source-backed predicate evidence, not a claim that the previous phase's hidden history contained such a call.

The exact inventory request is `GET /api/mcp` with `location[directory]` equal to the owned probe directory; stable GET translation preserves this path (`lib/api2/dialect.dart:98`). The pinned [MCP handler](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/server/src/handlers/mcp.ts) returns the location response's `data` array containing `name`, nested `status` and optional `integrationID`. The [MCP schema](https://raw.githubusercontent.com/anomalyco/opencode/b8cedc1a7a5e2916bbb65dc1d4b620729c261638/packages/schema/src/mcp.ts) defines connected as `status:{status:'connected'}`. Check exact server name `oc-ui` and nested connected state; expose only bounded booleans/fixed failure codes, never a failed status's error text. Inventory alone does not expose tools or `codemode`, so it cannot prove direct `show` availability. For a session-only allow, the source-qualified action is `oc-ui_show`: `{action:'oc-ui_show',resource:'*',effect:'allow'}`. The real call plus fresh matching success event supplies the missing execution proof.
