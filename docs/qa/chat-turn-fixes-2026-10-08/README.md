# Chat turn fixes — 2026-10-08

Branch `fe/chat-turn-fixes` from `feat/genui-fe` (`e2b3fe16`). Chat transcript only; no backend or protocol change.

## What changed

| # | Defect | Fix |
|---|---|---|
| 1 | After Stop, a Claude Code (Paseo) or OpenCode 2 turn ended silently. Only OpenCode 1 marks the last step "aborted"; `ServerGateway.abort` returns nothing and Paseo/OC2 leave no error. | The chat already remembers the prompt it stopped (`_stoppedPromptID`). `_stoppedTurnRow` (transcript_turns.dart) picks the row that ends that turn: the footer owner, or the prompt when nothing came back. Once the turn stops running, that row draws the kit's existing stopped line, "You stopped this reply." The stop carries over when the optimistic prompt id is swapped for the server's id. |
| 2 | The agent card tool showed as the raw `oc-ui_show`. | The general tool-name mapping (`_ToolContract.from`, tool_card_contract.dart) maps every `AgentToolAdapters.cardShowNames` entry to "Show card", with the card's own title after it. The server's title is ignored when it only repeats the tool id. |
| 3 | FC3: a stalled turn had no explanation. | `KitTurn` gains `stall: KitTurnStall?` (kit spec updated). It is drawn under the live line: one plain sentence for each `TurnStallKind` from `ConnectionController.turnStallFor`, then **Stop reply** (the existing `_abort`) and **Details**. Details shows the watchdog's facts as technical text. No contract or error text is used as copy. |
| 4 | Owner screenshot: opening running work showed two spinners and the same step label twice. | `KitWorkLine`: when running and opened, the chip reads "Hide steps" with no working mark. The running row in the list keeps the only spinner. When folded, nothing changes (decision 01B). |
| 5 | Owner screenshot: raw `task_notification` under a wrench. | `task_notification` now reads "Background task finished/failed/stopped", with its summary after it. Any other unknown tool id is shown as words ("render_mermaid_diagram" → "Render mermaid diagram") through `KitText.sentenceCase`, never as raw snake_case. |

The new copy is in `app_en.arb` and `app_ar.arb` (Arabic translated), and `flutter gen-l10n` was run.
