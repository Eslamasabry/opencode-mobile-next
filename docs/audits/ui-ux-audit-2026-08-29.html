Strong product underneath an overexposed interface

The app is capable enough for a controlled public preview, but too much capability is exposed at once. The next release should converge the experience around three goals: start or continue work, supervise active agents, and inspect or change output.

Recommended product model

Workspace ├── Current project/workspace context ├── Active and recent sessions └── Start a prompt Session ├── Conversation and live tools ├── Needs attention ├── Context / files / changes / review └── Session actions Activity ├── Needs attention across sessions ├── Running sessions └── Recently completed sessions More ├── Models and agents ├── Providers and MCP ├── Commands and skills └── Settings, privacy, diagnostics, setup

Highest-priority changes

Unify Mission Control + Requests

One Activity destination, one badge, and exact permission/question/form resolvers from every attention row.

Make Workspace session-first

Show context, active sessions, recent sessions, and quick ask before worktrees, managed workspaces, and project health.

Simplify compact composer

Keep the field and send/stop visible; move Commands, Attach, and Voice into one tools surface.

Expose queue versus steer

Do not hide a materially different delivery consequence behind long press. Use a labelled split/menu control while busy.

Remove the global text clamp

Honor the system scale and repair layouts at 0.8–2.5× rather than overriding accessibility preferences.

Finish semantic token migration

Centralize semantic colors, muted text, diff roles, type, spacing, radii, surfaces, motion, and icon vocabulary.

Make Changes the completion path

Files should expose changed files and route naturally into Review and back to the originating prompt.

Add accessibility gates

Automate tap-target, labelled-target, contrast, semantics, text-scale, and critical TalkBack checks.

Preview convergence release

  1. Collapse duplicate global surfaces into Activity.
  2. Reduce root app-bar actions and preserve useful identity on narrow screens.
  3. Make Workspace session-first.
  4. Simplify the compact composer.
  5. Make queue/steer and message actions visible.
  6. Add Files → Changes → Review → Prompt as one workflow.
  7. Finish flagship semantic token migration.
  8. Remove accessibility clamps and add automated/device gates.
  9. Normalize remaining raw errors and incomplete localization copy.
  10. Validate the hierarchy through real tasks with new, experienced, large-text, and TalkBack users.

Safe public-preview gate

  • One global Activity/attention entry and badge.
  • Useful composer width at narrow and large-text states.
  • Queue and steer visibly discoverable.
  • Critical flows operable at 2.5× text.
  • Tap-target, label, contrast, and semantic tests pass.
  • Safe server-controlled link confirmation.
  • No raw exception strings in default UI.
  • Flagship screens use shared semantic tokens.
  • First-run trust/security copy is clear.
  • English-only status is explicit if localization remains partial.
