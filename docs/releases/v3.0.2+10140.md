# OpenCode Mobile 3.0.2+10140

This update replaces 3.0.1 in place and keeps your data. It fixes the faults that 3.0.1 listed as known, and a few more found since. The agents on your phone keep the same versions as in 3.0.1, so this update downloads nothing for them.

## In short

- **Agent updates on mobile data always have their button.** After a restart or a dropped download, the waiting line on Home offers Download on mobile data again.
- **A stopped server reads stopped from the start.** It no longer looks connected for a moment when the app opens.
- **A conversation you stopped stays stopped.** Its sub‑agents no longer say Working, and a text reply you cut no longer reads Done.
- **A provider you removed can be added again** (issue 152).

## Fixed

- After the app restarts, or a download drops, before an agent update starts on mobile data, Home's waiting line shows Download on mobile data instead of only waiting for Wi‑Fi.
- A server you stopped shows as stopped from the moment the app opens, instead of looking connected for a moment first.
- In a conversation you stopped, sub‑agents no longer say Working with Stop buttons, and a text reply cut by your stop no longer reads Done. When you start a newer run in that conversation, the stop no longer applies to it.
- The Agents page names every agent that finished updating, not only one.
- In the change view, the row with the file's name keeps its normal height.
- A screen reader no longer reads out the letter logo of the fx agent; it still reads the agent's name beside it.
- A custom provider you removed can be added again. If you add one under the same name as a provider the app made for you before, the new entry replaces that old one.

## Known in this version

These are known and planned for a later update.

- A custom provider cannot yet be edited, and removing one does not ask you to confirm first.
- On a phone‑width screen, the top bar of the file review page cuts its action labels and can break a long file name mid‑word.
- On Home, the filter chips can look narrower for a moment when the page first appears.
- A sheet or menu that is open in a conversation closes when you rotate the phone.
- The layout for tablets and other wide screens is not in this release.
