# 1.1.1 release notes (draft)

## Fixed

- Opening a project in your phone's shared storage (for example
  `/sdcard/CodeAnything`) showed only hidden folders such as `.git`; the agent
  and the Files tab could not see `package.json`, notes or other files (#87).
  The app now explains and asks for Android's "All files access" the first
  time you open or create a project there, and the in-app Linux sees
  `/sdcard` and `/storage` once it is allowed. Projects in the app's own
  project space never ask. You can turn it off any time in Android Settings,
  under All files access.
- If your server runs in Termux, the app tells you in plain words to allow
  Termux storage (`termux-setup-storage`) instead of showing an empty folder.
- The Files tab says "Files are hidden" with an "Allow access to files"
  button, instead of an empty list, when access is the reason.

## Changed

- Glass is gone: the bottom bar, the side rail, the top buttons and the message box are solid again, which is faster and clearer. The old "Liquid glass was turned off" notice is gone with it.

## Added

- The home-screen widget shows "N need you" in its header when permission
  requests, questions or forms are waiting (#32). Tapping it opens Activity.
  It reuses the Quick Settings tile's cached count, so it needs no background
  work and shows nothing when the count is stale (over a day old).
- A new Quick Settings tile, "Background mode", pauses and resumes background
  mode (#34). It does the same as the notification's "Pause background"
  button, shows On, Paused, or "Off in Settings", and only works when
  background mode is switched on.

## Notes for maintainers

- Liquid glass removal: `shaders/kit_glass.frag` is deleted and `pubspec.yaml` no longer lists a `shaders:` entry, so this needs a new Shorebird release, not a patch. Old `oc.glassLiquid*` preferences are dropped on first load.

- New permissions: `MANAGE_EXTERNAL_STORAGE`; `READ_EXTERNAL_STORAGE`
  (to API 32) and `WRITE_EXTERNAL_STORAGE` (to API 29). Play Console needs the
  all-files-access declaration if this ships there; sideloaded builds do not.
- The AI Team's confined tier is not given shared storage.
- Needs a device to prove: the system page round trip on Android 11+, the
  `/sdcard` bind inside proot, and the Termux check on a phone without
  `termux-setup-storage`.
- Tile and widget changes need a device to prove: resuming from the tile
  starts the foreground service (if Android refuses, the tile opens the app),
  and the widget badge redraw after a permission request arrives. Native
  change, so it needs a new release, not a patch.
