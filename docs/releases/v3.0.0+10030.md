# OpenCode Mobile 3.0.0+10030

The first native release with its fixes: this build covers everything that was found and corrected since 3.0.0+10020 came out, on real phones and in long checks. It installs over 2.1.5 and over 3.0.0+10020 and keeps your data.

Change class: feature

**Migration.** Nothing to do. If you already updated to 3.0.0+10020 and "This phone" said "Not answering", it corrects itself the first time you open this build. The 3.0.0+10020 notes still apply to people coming from 2.1.5 (computers need OpenCode 2, 64-bit phones only, Chinese and Japanese not offered yet).

## What changed for you

### Conversations
- **A conversation opens where you left it.** Coming back keeps your reading place, Find, and the parts you had opened.
- **Words you typed are not lost.** New conversation keeps what you typed while the page was getting ready, and brings back what you typed and closed. An unsent Git save message survives leaving the page.
- **A stopped reply says Stopped, once.** A stop you made stays Stopped after a restart, and a refusal never reads as a server restart.
- **A reply that was cut off says so.** If the connection dropped, the conversation offers Send again or Continue. Send again sends your newest message once, with its files, and asks first if the earlier send was never confirmed.
- **A retrying reply says why** and offers another model.
- **Thinking effort on New conversation.** Pick how hard the model thinks before you send.
- **Models read as names.** "Opus 4.6 · 1M context" instead of a bracket tag, and models that share a name stay separate entries. The model list says it is loading instead of looking empty, and search filters as you type.
- **Choose the mode new conversations start in** under Settings > Model and mode.
- **A sub-conversation names its parent** and takes you back to it.
- **Continue with another agent** from any conversation, with a plain check of the folder first.
- **Hardware keyboard.** Find, next match, rename, terminal and the commands launcher have keys, and Ctrl+K opens the commands launcher.
- **The message box and the buttons around it stay put.** The jump to latest button and the phrase chips no longer sit on top of reply text, Tab and the arrow keys walk the whole conversation, and a letter you type goes to the field you just opened.
- **Long lines fade and scroll sideways** in code and command output instead of cutting a letter.
- **Thoughts fold under one line,** and the work line counts only work that happened.
- **Earlier messages are the conversation's first row,** not a control floating over it, and rows no longer slide over each other while a reply arrives.
- **Find marks its matches** in the conversation, the current one stronger, and says which match you are on.
- **Titles end at a word,** table cells keep words whole, and code runs to the edge of its block.
- **On a phone the approval mode is its shield alone,** so the model's name keeps its room in the message box.

### Other conversations
- **An edge light, if you want it.** Settings > Conversations > Other conversations > Edge light puts a small light on the screen's edge while you read a conversation. It shows when another conversation is working or needs you; tap it for the list, answer a request there, open a conversation and come back to where you were. Move it to any of six spots. Rings stays the default.

### Permissions
- **Allow or Deny at once.** Deny on the permission card denies immediately; a note you add goes to the agent as your words and stays visible under "You declined this".
- **The card shows what it would change.** A file edit names its file and previews the change, the answers are one pair, and "Always" says what it covers.
- **Declined is not failed.** A request you refused reads "You declined this" and keeps that line after later messages.
- **A malformed question from the agent says so** in plain words, and the message box says it is waiting for your decision.

### Home
- **The home reaches every conversation.** On OpenCode 2 it lists all projects' conversations, and a list the app could not read is no longer shown as "No conversations yet".
- **Answer a waiting question from its home row,** with Undo and Try again. A row says what it asks, and says when the server stopped or failed its run.
- **At most one notice,** worded in short plain sentences, and the New button never moves.
- **Pin once.** A pinned conversation goes to the top of Recent; filters narrow every section.
- **Share and Details on a row do what they say.** Share is offered only where the server can share.
- **Press back again to exit** is a short message, not a row.

### This phone and agents
- **One "This phone."** The agents on the phone are part of it, never a second server. Its connection follows the server to its port, and every build keeps its own port.
- **Agents install and sign in on the first press.** A failed install stays on its card with the reason and Try again; what an install needs is counted before it starts, and a blocked install explains itself and offers to stop the running one.
- **Honest agent states.** "Sign in needed", "Could not check" and "Not available yet" are no longer mixed up, and an agent set up at first use offers Set up.
- **Providers and sign-in.** Sign-in questions keep their choices, key-only providers open on the key, and one Back closes the page.
- **The App closed notice** is in plain words and says how to start OpenCode when it is still down. Updating, installing or stopping it yourself is no longer called a battery-manager kill.
- **A reply keeps notifying after you leave,** and the notification says what the conversation is doing.
- **Setup shows time left that counts down.**
- **This phone's pages agree.** App storage, Installed, Running, Export projects and Shared storage open with real answers and one number format.
- **Terminals** have plain names and numbers, a New terminal row, and a list that says which one runs.

### Computers and AI Team
- **A team on a computer** shows in AI Team: its project, tasks as a graph, agents with Pause, Nudge and Stop, the merge step, and its questions, failures and finished tasks in your notifications.

### Settings and Appearance
- **Menus and sheets are clearer,** including in Glass: the words stay readable over what lies behind them.
- **Glass is lighter on the phone.** It no longer works while the app is hidden, and a pane checks the colour behind its words only when that changes; before, it kept part of a processor busy the whole time. Two crashes in Glass are fixed: one while scrolling a long conversation, one on Back after a conversation's menu had been open.
- **Glass looks:** the New button is plain glass, the top area of a page has no outline, and menus, sheets and the conversations dock show the page behind them as colour instead of smudged words.
- **Brutal and Paper reach every part of a conversation:** the message box, its chips, your bubble, code, tables, menus and sheets.
- **One chosen-row look in every picker,** and a menu opens where you pressed, inside the screen.
- **One Back does one thing.** It closes the sheet, menu or dialog and leaves the page; the next tap after a sheet closes always works; the keyboard stays down after a sheet.
- **Pages fade under the bar** and above a pinned footer instead of ending in a hard line, and a row's title wraps to a second line instead of being cut.
- **The first-run question about reports** has buttons that say what they share.
- **Appearance:** choosing a style no longer replaces your background look, and the tabs stay under the bar in every style.
- **Settings pages say what is true:** Notifications follows the real server list and your Android setting, Storage opens the app's own storage, and Tools, Providers, Server configuration and Report a problem use plain words.
- **Settings search** finds pages inside Linux, ports, packages and storage.
- **Tools:** MCP tool servers can be added on every kind of server, and Commands and tools opens on Commands.
- **Projects:** each project is listed once, Rename is a visible pencil, Open works while a folder loads, and a missing folder offers to make it again.
- **Show tips again** also brings back the conversation's one-time hints; a tip opens in its own Help row.

### Languages
- **Eight languages are complete again** (English, Arabic, Spanish, French, Indonesian, Portuguese, Russian, Vietnamese), including the privacy policy and every new line. Arabic keeps its number forms.
- **Switching the language no longer leaves black bars** above and below the page.

### Files and terminal
- **The file viewer is a page of the app** with Back, Find and one menu. A file card opens the file by its place in the project, and Copy folder path says it copied.

### Updates and migration
- **After an update the app tells you which version is installed.** A second update is a no-op, the update notice clears itself, and a background connection you had on comes back.
- **A launch screen** shows the app's ground and mark, and an "Opening" line after two seconds.

### Stability and privacy
- **No crash on the first open after an update** and **This phone answers after it,** as in the first notes of this release: the widget, the port and the setup job faults are fixed.
- **OpenCode on this phone updates itself** to the version this app ships with, only while nothing is working.
- **All your conversations show.** Lists and long conversations are read to the end, not cut at 150.
- **Secrets stay hidden.** Values in MCP, shell and header settings are masked wherever they appear, including notifications, and sign-in field names are not treated as secrets.

## Known issues
- First published as a pre-release: neither 2.1.5 nor this app offers a pre-release as an update, so install it by hand from this page until it is promoted.
- Glass is still being tuned, and smoothness and the look of menus were checked on emulators, not yet on a range of real phones.
- Find brings the message with the match into view, not always the matching line inside a long message.
- The edge light is new and was checked on an emulator, not yet on a range of real phones.
- The Appearance page opens on Colours again after you leave a page inside it.
- The attach panel's icons have no words under them.
- "Show reasoning" opens and closes thoughts but does not hide them yet.
- A pin made from a conversation's relations page reaches the home only after a restart.
- A home row for a stop made in an older build stays "Interrupted".
- Rows kept only on this phone do not show their server's name.

## Technical changes

### Fixed
- The "This phone" profile follows its server's port on every refresh; each build keeps its own port and returns to it; the port check binds the way a server does.
- A widget refresh before the one-time migration finished no longer ends the app; a refused foreground-service start keeps its notification promise.
- Cursor pages send their size with every cursor, so lists no longer end at 150 rows; a page whose rows cannot be read is not an empty list; a client closed mid-read is a failure.
- The automatic OpenCode update starts, and setup jobs are no longer refused on phones whose last saved job came from the 2.x app.
- Model entries are keyed by their own id; bracket tags read as the variant.
- Delivery remembers the person's Stop across a restart; a reply is "cut off" only after the server says nothing runs.
- Sheets and dialogs hand focus back once gone; one keyboard measurement is used app-wide; edge-to-edge is asserted on every resume.
- The version check of an agent kills its whole process group and gets one more run when slow; install, removal and sign-out no longer wait behind page checks.
- MCP, LSP, formatter and header values from a server's config are masked as secrets in lists, shell lines, fragments and notifications.
- The glass ink sampler never waits on the GPU from the UI thread and keeps one render target; a failure there is a missed sample.
- A typed home path in the project dialog says why it is refused; stray backslashes before apostrophes are gone.
- Every kit layer is recorded and drawn through one guard, so a picture can never contain itself (the Glass scroll crash).
- Glass tickers stop while the window is hidden, and a pane samples the ink behind its words only when what lies behind it changed.
- A phone that refuses the thermal listener still starts the app.
- A kit layer recording carries a copy of the density, never the draw scope itself (the Glass crash on Back); the step list's timer parks while the app is hidden.
- A chip row never drops a chip; the one that does not fit is cut by the edge fade. A closed modal leaves no layer that takes touches.

### Changed
- Glass menus and sheets are the bar's clear glass, with words held by softened detail instead of frost.
- Settings pages scroll under a floating bar; Appearance tabs are the bar's second row.
- The home, All conversations and the team pages read one pin store, one model-name rule and one count rule.
- Agents on the phone run in a compatibility mode when Node needs it.
- Gemini CLI is no longer offered; an installed copy is kept.
- New text in all eight languages goes through the translation pipeline.

### Internal
- A computer team engine (reads, event stream, controls) and the Continue with handoff check.
- Tests for the release script's promises and the release-only checks; an Android unit-test lane.
- Debug logging for the automatic update is off unless a tester switches its tag on.
