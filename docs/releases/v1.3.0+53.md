# OpenCode Mobile 1.3.0+53

Claude Code chats now come with their files, changes and terminals; waiting questions can be answered straight from the conversation list; and you can tidy, steer and repair your work from the phone.

## What changed for you

- **Claude Code chats** have **Files**, **Changes**, **Terminal**, **Worktrees**, **Fast mode** and **Import from Claude Code**.
- Answer a waiting question or **Allow** right in **Conversations**; finished ones get **Done**.
- **Delete** and **Archive** a conversation are back; **AI Team** can pause, delete and force-stop.
- Plain-word errors; more languages.

Pictures, before and after: [docs/releases/v1.3.0+53/README.md](https://github.com/Eslamasabry/opencode-mobile-next/blob/v1.3.0%2B53/docs/releases/v1.3.0%2B53/README.md).

## Technical changes

### Added
- Claude Code and Pi chats (through the computer's helper):
  - **Files**: browse and read the project's files, and find them by name.
  - **Changes**: the agent's uncommitted changes and the branch view.
  - **Worktrees**: list, create and delete.
  - **Terminal**: open terminals on the computer; type, rename and stop them.
  - Questions and plans from Claude Code appear as choices you tap.
  - **Import from Claude Code** on **New conversation**: pick a conversation started in Claude Code on the computer and carry on.
- **Fast mode** and an agent's other switches: a chip beside the model chip opens **Claude Code settings**; each switch saves at once.
- **Conversations** list:
  - A conversation waiting on you shows its request under the row: **Allow once**, **Always allow**, **Reject**, or a question's choices. This works for OpenCode, Claude Code and Pi.
  - An answer is held for 3 seconds with **Undo**, in the list and in the chat; leaving the chat sends it at once.
  - A green **Done** tag marks a conversation that finished since you last opened it.
  - **Archive** and **Delete** in a conversation's own menu.
- **Agent cards** on the phone's in-app Ubuntu server: an agent can show a card with choices, a form, a table or a chart; a single choice answers on tap, and **Undo** restores your choice, the form values and photos.
- Connectors: a suggested-connector card connects an MCP server in place (**Connect**, sign-in, readiness), and agents and you can search the connector catalogue at once.
- Chat:
  - The work line opens in place to an inline step timeline; file writes and edits preview in place.
  - Images in replies show as tiles; photos you send show as thumbnails that open full size.
  - Your agent's name and model are shown before the first message.
- **Update agents on <computer>** on the server page, with a confirmation, progress and an automatic reconnect.
- **Check for agents again** on the server page, so signing in on the computer is noticed without reconnecting.
- **Search inside files** on OpenCode servers: the file and line of every match.
- AI Team:
  - **Pause / Resume project** and **Delete project** (the folder and files on the computer stay).
  - **Force stop** an agent, also offered when a normal Stop didn't work.
  - **Scheduled jobs** with plain schedules ("Every day at 09:00"), switched on or off.
  - Workers' questions show their text and choices; tool approvals can be answered.
- **Usage** shows the busiest days; plan limits say when they reset; agents say which model they use.
- **Report a problem** can attach a saved crash report, if you turn it on. **Recent errors** and recent app exits are listed in plain words, problems first, each crash once; the technical text is under **Details**.
- A notice says when Android paused the background connection (daily limit, battery restriction or app closed), with **Resume**.
- Japanese, Chinese, Spanish, Portuguese and Russian for first run and chat, offered in the language pickers (a phone in another language reads English); Arabic is now fully translated; Android notifications and the widget follow the app language.
- Agents on the phone:
  - **Welcome** leads with the phone as **Recommended**; setup shows the whole journey (install, name a project, chat) with its time.
  - Sign-in with **Open** and **Copy** buttons; **Signed in** only after a real check, with the account and **Sign out**; an agent that needs sign-in says so instead of "Checking sign-in..." forever (#95).
  - **Remove agent** frees its space.
  - The approval chip shows only for agents that ask before acting.

### Changed
- Tool steps in Claude Code chats show what the tool answered (MCP results, searches, fetched pages, sub-agents, skills); tool names read in words (**Load tools**, MCP tools with their server); permission requests show exactly what they ask, with **Always allow** only when the agent suggests a rule; plans read as formatted text.
- Claude chats list only Claude models with Claude's thinking levels; the message box says **Ask Claude Code...** or **Ask Pi...**; the model chip shows the model's name, never a raw id, and the chips above the message box stay on one row.
- Server page: **Edit** and **Remove** name the server; a check shows the version and which agents are ready; more rows under **Available on this server**; the switch button names where it switches to.
- Conversations that failed carry a **Failed** tag; new ones read **New conversation**; OpenCode 2 rows no longer show a wrong Git badge.
- Tools is one page with tabs; voice licences moved to **About**.
- While Claude waits for you, the live line holds still and stops the turn clock; a stopped turn and a stalled one say so.
- One progress indicator while switching or reconnecting; the "app was closed" notice folds away 15 seconds after the phone's server is back.
- The phone's agent runtime pauses when idle to save battery, with **Resume** from the notification, and comes back after the app is reclaimed.
- Numbered lists start at their first number; a command block shows $ only where a command starts.

### Fixed
- **Delete** and **Archive conversation** had disappeared from the conversation's menu; they are back, and each confirms by name.
- The **Files** tab no longer appears on servers without project tools.
- Opening a folder on some OpenCode servers failed with technical text; it now opens. Loading models, commands, older conversations and connecting explain problems in plain words, with the technical text under **Details**.
- Failures reaching the computer's helper said "It changed on the server in the meantime"; they now say the computer couldn't be reached.
- A reconnect while Claude is working restores the live turn and **Stop**; short link drops stay quiet; Claude conversations in the list stay live when the helper starts slowly.
- An AI Team agent the host can't start said "stopped unexpectedly"; it now gives the reason once, with the agent's page name.
- Markdown pictures in replies no longer show as raw text.
- Long access tokens are masked in shared problem reports, crash reports and performance traces.
- The phone runtime restarts after a crash and comes back after a reboot or app update; agent installs reserve enough space first and repair an interrupted install.
- The download size reads correctly in right-to-left languages.

### Known limitations
- Search inside files works on OpenCode servers only; Claude Code and OpenCode 2 can't search file contents.
- AI Team can't undo a merge or create and delete scheduled jobs; the AI Team controls are checked by tests, not yet on a live host.

### Upgrading
- Installs over the previous public release (same signing key). Saved servers, sign-ins and settings are kept.
- Builds signed with another key (test builds) need an uninstall first. That removes the app's local data, but not your servers' data.
