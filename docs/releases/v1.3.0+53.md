# OpenCode Mobile 1.3.0+53

Claude Code chats now come with their files, changes and terminals, and you can tidy, steer and repair your work from the phone.

## What changed for you

- **Claude Code chats** have **Files**, **Changes**, **Terminal** and **Worktrees**, plus **Fast mode** and **Import from Claude Code**.
- **Delete** and **Archive** a conversation again.
- **AI Team**: pause, delete or force-stop from the phone; an agent that can't start says why.
- Steps show **what each tool answered**, and problems are explained in plain words.

Pictures, before and after: [docs/releases/v1.3.0+53/README.md](https://github.com/Eslamasabry/opencode-mobile-next/blob/v1.3.0%2B53/docs/releases/v1.3.0%2B53/README.md).

## Technical changes

### Added
- Claude Code and Pi chats (through the computer's helper):
  - **Files**: browse and read the project's files.
  - **Changes**: the agent's uncommitted changes.
  - **Worktrees**: list, create and delete.
  - **Terminal**: open terminals on the computer; type, rename and stop them.
- **Fast mode** and an agent's other switches: a chip beside the model chip opens **Claude Code settings**; each switch saves at once.
- **Import from Claude Code** on **New conversation**: pick a conversation started in Claude Code on the computer and carry on.
- **Update agents on <computer>** on the server page, with a confirmation, progress and an automatic reconnect.
- **Check for agents again** on the server page, so signing in on the computer is noticed without reconnecting.
- **Search inside files** on OpenCode servers: the file and line of every match.
- AI Team:
  - **Pause / Resume project** and **Delete project** (the folder and files on the computer stay).
  - **Force stop** an agent, also offered when a normal Stop didn't work.
  - **Scheduled jobs** with plain schedules ("Every day at 09:00"), switched on or off.
  - Workers' questions show their text and choices; tool approvals can be answered.
- Inline step timeline; images in replies show as tiles; a suggested-connector card connects MCP servers in place, and connector search answers at once.
- Usage shows the busiest days; plan limits say when they reset.
- **Report a problem** can attach a saved crash report, if you turn it on.
- Japanese, Chinese, Spanish, Portuguese and Russian for first run and chat; about 2,500 more Arabic strings; Android notifications follow the app language.
- Agents on the phone:
  - Sign-in with **Open** and **Copy** buttons; **Signed in** only after a real check, with the account and **Sign out**.
  - **Remove agent** frees its space.

### Changed
- Tool steps in Claude Code chats show what the tool answered (MCP results, searches, fetched pages, sub-agents, skills); permission requests show exactly what they ask, with **Always allow** only when the agent suggests a rule.
- Claude chats list only Claude models with Claude's thinking levels; the message box says **Ask Claude Code…** or **Ask Pi…**; the model chip shows the model's name.
- Server page: **Edit** and **Remove** name the server; a check shows the version and which agents are ready; more rows under **Available on this server**.
- Conversations that failed carry a **Failed** tag.
- Tools is one page with tabs; voice licences moved to **About**.
- The phone's agent runtime pauses when idle to save battery, with **Resume** from the notification.

### Fixed
- **Delete** and **Archive conversation** had disappeared from the conversation's ⋯ menu; they are back, and each confirms by name.
- Opening a folder on some OpenCode servers failed with technical text; it now opens. Loading models, commands, older conversations and connecting explain problems in plain words, with the technical text under **Details**.
- Failures reaching the computer's helper said "It changed on the server in the meantime"; they now say the computer couldn't be reached.
- A reconnect while Claude is working restores the live turn and **Stop**; short link drops stay quiet.
- An AI Team agent the host can't start said "stopped unexpectedly"; it now gives the reason.
- Long access tokens are masked in shared problem reports, crash reports and performance traces.
- The phone runtime restarts after a crash and comes back after a reboot or app update; agent installs reserve enough space first.

### Known limitations
- Search inside files works on OpenCode servers only; Claude Code and OpenCode 2 can't search file contents.
- AI Team can't undo a merge or create and delete scheduled jobs; the AI Team controls are checked by tests, not yet on a live host.

### Upgrading
- Installs over the previous public release (same signing key). Saved servers, sign-ins and settings are kept.
- Builds signed with another key (test builds) need an uninstall first. That removes the app's local data, but not your servers' data.
