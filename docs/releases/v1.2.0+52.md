# OpenCode Mobile 1.2.0+52

Claude Code on your phone beside OpenCode, every connection on the phone in one conversation list, and the first release you can update over the air.

## Highlights
- **Claude Code on your phone.** It runs inside the in-app Ubuntu through its helper. Start a conversation with it from **New conversation**, using its own models. You can approve its requests, send it pictures and use its own `/` commands. Old conversations reopen with their memory. Sign in with Claude's own login on a terminal: the app never sees the code. Codex, Gemini CLI, Qwen Code, Goose and Pi use the same path. *Claude is checked on an emulator; the other agents still need a device check.*
- **Claude's sub-agents open like OpenCode's.** Tap a **Delegated to …** row to see that sub-agent's own steps and answer, live. Its page links back to the main conversation.
- **Every connection in one list.** Conversations from the in-app Ubuntu, Termux and Claude Code show together. Each one opens on its own connection, without switching servers.
  - Each row starts with where it runs, for example **Claude Code** or **OpenCode · Termux**.
  - **Connections in this list** lets you hide any source. Servers on other computers show only when you turn them on.
  - A server that isn't answering is named, with **Try again**. Conversations from last time show at once after a restart.
- **Clearer names.** The phone's servers are **In-app Ubuntu** and **Termux**. The top button names where new conversations start, plus how many other connections the list shows (**In-app Ubuntu +2**).
- **Conversations first.** The tabs are Conversations, Files and Settings. There is a project filter, and a new **Open a project** sheet: New project, Search this phone, Opened before.
- **Over-the-air updates.** This is a Shorebird release, so small fixes can arrive without installing a new APK.

## Added
- The home-screen widget shows how many requests need you (#32). A Quick Settings tile pauses and resumes background mode (#34).
- Plain `http://` to private network addresses, after a warning and a confirmation (#85).
- Syntax colours in the diff view (#26).

## Changed
- The list says what is still loading ("Loading Termux conversations…"). Conversations that arrive later slide in instead of popping in.
- A conversation being opened says **Opening…**.
- The **Thinking** line shows a soft light moving over its words, instead of a pulsing dot. The Animations setting and the system's reduced-motion option are respected.
- Claude's command list uses the sheet's full width.
- The model button never shows a raw model id.
- The glass look is gone: the bars, sheets and message box are solid again.

## Fixed
- Projects in shared storage (`/sdcard/…`) showed only hidden folders (#87). The app now asks for **All files access** the first time you open one.
- Claude Code:
  - A conversation keeps the model chosen for it.
  - Replies no longer read as cut off.
  - An expired login says so, with **Sign in with Claude Code**.
  - A reopened conversation keeps its title.
- "Claude Code stopped in the background" no longer flashes at start-up.

## Known limitations
- Not yet checked on a physical phone: alerts for Termux conversations while the app is in the background, and installing agents other than Claude Code.
- Claude's sub-agents can't take messages of their own. You write to the main conversation.
- Conversations can't be deleted or archived from the app.

## Upgrading
- Installs over 1.1.0 and earlier public releases (same signing key). Saved servers, sign-ins and settings are kept.
- Builds signed with another key (test builds) need an uninstall first. That removes the app's local data, but not your servers' data.
- New permission: **All files access**. It is asked only when you open a project in shared storage, and you can turn it off in Android Settings.
