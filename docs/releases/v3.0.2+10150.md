# OpenCode Mobile 3.0.2+10150

This update replaces 3.0.1 in place and keeps your data. It fixes the faults that 3.0.1 listed as known, stops the app from running out of memory in long conversations, lets you edit and remove a provider you added yourself, and offers newer versions of four agents on your phone. The app asks before it downloads them.

## In short

- **Long conversations no longer close the app.** A long conversation with a busy command could use up the app's memory until it closed. Six fixes take that pressure away.
- **A reply's steps sit where they happened.** They appear between the paragraphs they came between, not above the message.
- **Edit and remove a provider you added.** With clear messages when OpenCode on this phone does not restart.
- **Newer agents on your phone**: the helper, Antigravity, Qwen Code and Cline. The app asks before it downloads them.
- **Agent updates on mobile data always have their button**, and **a stopped server or conversation reads stopped**: the faults 3.0.1 listed as known.

## New

- A provider you added yourself can now be edited (its name, address and models) and removed. Removing one asks you first and says what goes with it. When OpenCode on this phone has to restart to load the change and does not, the app says so plainly and offers the way forward. This works in all the app's languages.

## Agents on this phone

If you use coding agents on your phone, this update offers newer versions of these. The app asks before it downloads them and shows the size; on mobile data it says so and waits for your yes. Sizes are for a phone (download, then space taken once installed).

- The agents' helper, 0.17.3. With it, Antigravity no longer gives every model the thinking levels of its default model.
- Antigravity 1.5.15: about 92 MB to download, 257 MB installed.
- Qwen Code 0.28.4: about 45 MB to download, 163 MB installed.
- Cline 3.0.75: about 55 MB to download, 165 MB installed.

Claude Code, Codex, OpenCode and the other agents keep the versions they had in 3.0.1.

## Fixed: running out of memory

- The app could run out of memory and close in a long conversation with a busy command. These fixes take that pressure away:
  - The error logger can no longer close the app itself when memory runs short.
  - A long conversation is no longer copied whole every time it updates.
  - The facts shown on a reply's steps are worked out only for the steps that changed.
  - The problem report is no longer rewritten over and over while the app talks to the server.
  - A reply that is still running no longer copies its whole text again on every update.
  - A very large file or photo you attach is no longer read whole into memory: the app says it is too large instead of closing.

## Fixed: conversations

- A reply's steps now appear between the paragraphs they came between, not all above the message.
- The running light on the steps follows the newest step.
- A command that an agent left running in the background shows as running, never as Stopped.
- An edit preview you open scrolls on its own and no longer fights the page's scroll.
- Sheets and menus that are open in a conversation stay open when you rotate the phone.
- Right after you send a message, a false "No reply came back" no longer appears.
- A conversation you stopped and open again no longer shows its reply as running for a moment.
- A conversation you open shows its loading picture from the first moment, instead of an empty page first.
- In a conversation you stopped, sub‑agents no longer say Working with Stop buttons, and a text reply cut by your stop no longer reads Done. When you start a newer run in that conversation, the stop no longer applies to it.

## Fixed: Home, agents and other pages

- After the app restarts, or a download drops, before an agent update starts on mobile data, Home's waiting line shows Download on mobile data instead of only waiting for Wi‑Fi.
- A server you stopped shows as stopped from the moment the app opens, instead of looking connected for a moment first.
- On Home, the filter chips have their full width from the moment the page appears.
- The file review page's top bar never cuts the words on its buttons, on a phone or a wide screen, and keeps a long file name whole.
- The help in "Your own agent" and "Your own provider" opens inside the sheet, instead of in a second sheet on top.
- The Agents page names every agent that finished updating, not only one.
- In the change view, the row with the file's name keeps its normal height.
- A screen reader no longer reads out the letter logo of the fx agent; it still reads the agent's name beside it.
- A custom provider you removed can be added again. If you add one under the same name as a provider the app made for you before, the new entry replaces that old one.

## Known in this version

These are known and planned for a later update.

- The list of a reply's steps can still jump while new steps arrive, and the page can move when you have scrolled up. This part is being rebuilt and comes in the next update.
- When a conversation opens, its page can shift once, for a single frame.
- On the floating conversation page, the round "go to the newest" button can sit over the text.
- On the floating conversation page, there is a gap above the message box.
- A task running in the background shows no start and end time yet, and its status check can read "Other".
- The first message in a new conversation can fail with "model not found" when the model you chose is no longer offered. Pick another model and send it again.
- The layout for tablets and other wide screens is not in this release.
