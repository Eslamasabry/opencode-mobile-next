# 1.2.0 release notes (draft, 2026-10-06)

Candidate: `feat/phone-setup-v2` at `b794f98a`, test APK 1.1.0 (2165). The
full suite passed: 1058/1058 files, 2 shards. Not yet merged to `master`.
It supersedes `v1.1.1-draft.md`, whose fixes are included below.

## Added

- **Claude Code on your phone, beside OpenCode.** Claude Code runs inside
  the in-app Ubuntu through its helper (Paseo).
  - Start a conversation with it from New conversation, using its own
    models.
  - Approve its requests, send it pictures and use its own `/` commands.
  - Reopen old conversations: they resume with their memory.
  - Sign in with Claude's own login on a terminal. The app never sees the
    code.
  - Other agents (Codex, Gemini CLI, Qwen Code, Goose, Pi) use the same
    path. These are tested in code only, not yet on a device.
- **Claude's sub-agents open like OpenCode's.**
  - Each "Delegated to …" row opens that sub-agent's own steps and answer,
    live.
  - Its page links back to the main conversation.
  - It is read-only, because a sub-agent answers only its main
    conversation.
- **Every connection on this phone in one list.**
  - The in-app Ubuntu, Termux and Claude's conversations show together.
  - Each opens on its own connection, without switching servers.
  - A connections chip ("Connections in this list") hides any of them.
  - Servers on other computers join only when you turn them on.
  - Each row starts with its agent: "Claude Code", or "OpenCode · Termux".
  - A server that can't be reached is named, with Try again.
  - Conversations from last time show at once after a restart.
- **Clearer names.** The phone's servers are "In-app Ubuntu" and "Termux".
  The top button says where new conversations start and how many other
  connections the list shows ("In-app Ubuntu +2").
- **Conversations-first layout.** The tabs are Conversations, Files and
  Settings. There is a project filter sheet and a new Open a project sheet
  (New project, Search this phone, Opened before).
- **Home-screen widget and Quick Settings:**
  - the widget shows how many requests need you (#32);
  - a Quick Settings tile pauses and resumes background mode (#34).
- **Plain http to private network addresses,** after a warning and a
  confirmation (#85).
- **Syntax colours in the diff view** (#26).

## Changed

- The list says what is still loading ("Loading Termux conversations…").
  Rows that arrive later slide in instead of popping.
- A row being opened says "Opening…".
- The "Thinking" line has a soft light sweeping over its words instead of a
  pulsing dot. The Animations setting (Calm, Off) and the system's reduced
  motion are respected.
- Claude's commands list uses the sheet's full width. The `/` list always
  leads to Show all on a phone.
- The model chip never flashes a raw model id: names are remembered per
  server.
- Glass is gone: the surfaces are solid again.

## Fixed

- Projects in shared storage (`/sdcard/…`) showed only hidden folders (#87).
  The app now asks for All files access the first time.
- Claude:
  - the model chosen for a conversation is kept;
  - replies no longer read as cut off;
  - an expired login says so in words, with "Sign in with Claude Code";
  - a resumed conversation keeps its title;
  - the model chip no longer falls back to "Loading" after a turn;
  - its permission mode is no longer shown as part of the model
    ("default · Opus 5.5").
- "Claude Code stopped in the background" no longer flashes at start-up
  while the app restarts the helper.
- The helper is checked and started at app launch, beside the in-app
  server, so Claude's conversations arrive sooner.

## Notes for maintainers

- This needs a **new Shorebird release, not a patch**: 1.1.0 was built
  with plain Flutter, so there is no Shorebird base. Native, asset and
  pubspec changes are included too (glass shader removed, storage
  permissions, Kotlin agent sign-in).
- New permissions: `MANAGE_EXTERNAL_STORAGE`; `READ_EXTERNAL_STORAGE` (up
  to API 32) and `WRITE_EXTERNAL_STORAGE` (up to API 29). Play Console needs
  the all-files-access declaration if this ships there.
- New preferences, all profile-scoped so the deletion sweep removes them:
  - `oc.chatListShown.<id>`
  - `oc.sideFeed.<id>`
  - `oc.modelNames.<id>`
  - `oc.agentFeed.<id>`
  - `oc.phoneAgentsUsed.<id>`
- Paseo hello capabilities now include `provider_subagents` and
  `projected_subagent_timeline`. Helper version 0.9.2.
- Deliberately not done:
  - Delete or archive conversations (owner, 2026-10-06: no).
  - Moving New conversation onto Claude's own connection (it works as is;
    that change would only add risk).
- Still to be proven on a real phone: alerts for Termux conversations
  while the app is in the background; installing another agent (Gemini,
  Qwen) end to end.
