# OpenCode Mobile 2.1.1+58

This release fixes AI Team on phones with Android 16 and newer (issues #111 and
#112) and makes the phone's local OpenCode server safer. Nothing else changes.

Change class: fix

## What changed for you

- **AI Team turns on with Android 16's file protection.** The safety check
  no longer fails on Android 16 and newer, and OpenCode starts again inside
  the protection afterwards. Nothing the check requires has been loosened.
- **OpenCode on the phone is no longer stuck after a failed start.** Start
  and connect brings it back without clearing your data.
- **A team runs on the OpenCode version the app installs** (2.1.x), not only
  on 2.0.29.
- **New projects work after AI Team is on.** The app now makes the folder and
  its Git repository itself, so it no longer depends on a command the
  protection blocks. Projects look the same as before.
- **Adding a project to a team works with Termux** (issue #112). The team's
  store is set up with the OpenCode command the phone actually has.
- **A team starts before you open any chat**, and keeps working after you
  restart OpenCode from Settings.
- **Safer local server.** The phone's local OpenCode server password no
  longer appears in the list of running processes, and the server refuses to
  start without its password.
- **Clearer Details.** When a step fails, Details and Copy all name the exact
  step, and a failed Termux turn-on shows the setup's own output.

## Technical changes

**Boundary proof on Android 16** (`oc-engine-boundary-probe`)  
Each forbidden action runs in a throwaway child, and Android 16's seccomp
answer (SIGSYS) counts as denied. A hidden `/proc/<app>` counts as denied too.
_For: anyone turning on AI Team on Android 16+. Accessibility: no screen
change; the step line stays inside Details._

**Protected restart**  
The installer and server gates read up to 16 launcher lines before their
header, so bionic's linker warnings no longer stop a confined start. A launch
that fails before its permit clears its own ticket.
_For: everyone with AI Team on. Accessibility: no screen change._

**OpenCode 2 versions for the team**  
The engine accepts 2.0.29 and later patches, 2.1.x and 2.2.x after checking
the server's API contract.
_For: everyone using AI Team. Accessibility: no screen change._

**New projects made by the app**  
A new folder in the phone's projects is made with its Git repository by the
app (same settings and branch as before, one empty first commit), not by
`git init` inside the protected Linux.
_For: anyone who makes projects on the phone. Accessibility: no screen change._

**Team store on Termux**  
`gc init` runs with the agents' `opencode` on PATH (phones with OpenCode 2
have only `opencode2`) and Dolt's identity set, so the store is made.
_For: AI Team on Termux. Accessibility: no screen change._

**Team status and restarts**  
Busy evidence reconciles with no chat folder known, and the engine accepts an
OpenCode restarted by the app without trusting a different server.
_For: everyone using AI Team. Accessibility: no screen change._

**Local server password**  
The launcher, its readiness check and the built-in Linux password write read
the password from its file or stdin inside the process that needs it; it is
never a process argument. One-time upload tokens go to curl as private config.
_For: everyone running OpenCode on the phone. Accessibility: no screen change._

### Known limitation

- If OpenCode stops while a team worker is mid-reply, that task may need to
  be started again; a Resume for this comes in the next update.
- Once AI Team has been turned on, Add tools (Python, voice typing) stops
  with an error, and the protected Linux refuses `chmod`, so run a script
  with `sh script.sh` instead of making it executable. Installing packages
  with `npm` or `apt-get install` still works. Add the tools you want before
  turning AI Team on; the next update fixes this.

### Upgrading

- Installs over 2.1.0 and earlier public releases (same signing key). Saved
  servers, passwords, conversations, drafts and settings are kept.
- If OpenCode on the phone is stuck after turning on AI Team on 2.1.0, open
  the app after the update and use Start and connect.
