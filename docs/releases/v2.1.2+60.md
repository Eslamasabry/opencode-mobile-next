# OpenCode Mobile 2.1.2+60

This release brings Google's Antigravity CLI to the phone in place of Gemini
CLI (issue #116), adds a way to add an agent from New conversation, and lets
you pick a GitHub repository when you add a Git remote (#114).

Change class: fix

## What changed for you

- **Antigravity CLI on the phone** (issue #116). Google has moved personal
  Gemini CLI access to Antigravity (`agy`). The app now installs it on the
  phone and you sign in with Google's own sign-in in the terminal. Chats with
  it work like the other phone agents.
- **Add an agent from New conversation.** The agent row starts with an
  "Add an agent" card. It opens the phone-agents setup and brings you back to
  your draft with the new agent ready to pick.
- **Pick a GitHub repository for a Git remote** (#114, thanks to the
  contributor). After you sign in to GitHub, the Git remote step lists your
  repositories, private ones marked, instead of asking you to type the
  address.

## Technical changes

**Antigravity CLI (`agy`)**  
The official agy 1.5.0 Linux build, pinned by checksum, runs through the
existing Paseo ACP route. Sign-in happens in the terminal with Google's own
flow; the app only checks, read-only, whether the agent is signed in. Native
admission, removal and per-profile clean-up cover the new agent. Gemini CLI
users see a short note on the move.
_For: anyone who used Gemini CLI on the phone. Accessibility: English and
Arabic guidance; the sign-in is Google's terminal flow._

**Add an agent card**  
A kit card in the first row of the agent grid; it leads the empty state.
_For: everyone starting a conversation. Accessibility: 48 dp target,
screen-reader button label, right-to-left layout in Arabic._

**GitHub repository picker**  
The repository list uses the device-flow sign-in token; a rejected token asks
for a new sign-in, as a rejected push does. "No repositories" shows under the
button.
_For: anyone adding a Git remote. Accessibility: a standard choice sheet,
English and Arabic copy._
