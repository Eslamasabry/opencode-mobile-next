# OpenCode Mobile 2.1.3+61

This release fixes setting up the phone's built-in Linux on phones where the
download tool crashes (issue #117). Nothing else changes.

Change class: fix

## What changed for you

- **Built-in Linux sets up even when its download tool crashes** (issue
  #117). On some phones the download tool inside the built-in Linux (curl)
  crashed while fetching Node.js, and setup stopped with "Could not install
  Node.js". The app now downloads the file itself with Android's own
  networking and setup carries on. The file is still checked against its
  pinned checksum, so nothing unverified is installed.
- **Clearer Details.** If every way of downloading fails, Details says that
  the download tool crashed, in plain words, instead of an exit number.

## Technical changes

**Download fallback in setup**  
`oc_download` treats a curl exit of 128 or more (killed by a signal) as a
crashed tool, also on the size probe. It then asks the app to fetch the file
(`::oc fetch <url> <path> <sha256>`, answered through two marker files), and
falls back to `curl --http1.1` and `wget` when the app does not answer. The
app-side download is https only, writes only inside the built-in Linux, resumes
a partial file and verifies the pinned SHA-256.
_For: anyone setting up built-in Linux. Accessibility: no screen change; the
step line and Details read as before._
