## Context capsule contract

- Entry: Chat's existing Add menu. A capsule is a working copy for the currently named task, not another inbox or attachment store.
- Add up to eight labeled excerpts: Note, Error and Code are starter labels, freely editable. Clipboard text is read only on explicit Paste. Each excerpt is bounded to 16,000 characters; the rendered bundle to 32,000.
- The existing file picker supplies supported images. Its five-file, 10 MB per-file and 20 MB aggregate limits include attachments already in the composer. Unsupported attachment capability leaves text useful and explains the limitation.
- Preview, edit and removal affect only the working copy. Back/Cancel discard unapplied content. It is transient while open; recovery of an unapplied capsule after process death is not claimed.
- Apply appends labeled text and selected images to the original draft without sending or replacing its existing contents. A changed owner, location, session, route or draft refuses application. Scope invalidation is permanent even if the connection returns to the old location.
- Applied content uses existing session-draft text and attachment references/blobs. Restart, write-refusal handling and profile deletion follow that existing storage path; no migration or new preference key.
- The ordinary composer save warning remains authoritative if persistence fails. An applied-but-unsaved draft is not described as saved.
